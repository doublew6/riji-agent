# Riji interface design entry

Read [the visual design guidelines](../docs/DESIGN.md) before proposing, implementing, or reviewing any product page.

The current direction is **Warm Desk / Muted Deep Green**: warm cream surfaces, muted dark greens, modern sans-serif typography, and restrained technical details. The canonical repository tokens, component defaults, approval boundaries, and review criteria are defined only in `docs/DESIGN.md`; do not duplicate them here.

Page layouts and behavior remain governed by each page's latest approved requirements. Historical screen mockups are not frozen requirements. The PRD-directory master and the repository copy of the guidelines must stay on the same version.
