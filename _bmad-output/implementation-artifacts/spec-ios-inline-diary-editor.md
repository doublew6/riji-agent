## Intent

**Problem:** Today displays an invented starter template as read-only blocks and requires a second input box, a section picker and Save paragraph. The user explicitly requires their existing Obsidian template and typing directly in the document body, including editing existing text.

**Approach:** Today becomes one continuous editable Markdown document with heading typography. Tapping a position edits there. Manual edits save locally without a separate append form or repeated confirmation. Keep date, directory, microphone and a concise save status. Use the selected original template for a new day; retain existing documents.

## Boundaries & Constraints

**Always:** Preserve the user's original template bytes and unsupported syntax; only supported date substitutions occur. Preserve pre-existing source, tests, drafts, recordings and receipts. Local manual editing is now authorized; retain revisions and both sides of a source conflict. Differentiate saved versus unsaved/error states. Retain Chinese composition, cursor and undo during autosave. Raw Markdown is authoritative; presentation must never serialize a lossy reconstruction. Preserve metadata and AI provenance during ordinary edits, with AI sections identified. Root will copy the privately located actual daily template into the normal Simulator namespace and verify exact bytes; private contents never enter source/fixtures.

**Never:** Modify Feishu/Hermes/Air writers, deploy, commit, reset Simulator or delete previous work. No personal template bundled for all users. No broad voice rewrite: its separate review remains paused with known findings. Do not replace or silently commit a pre-existing append draft on opening.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|---|---|---|---|
| New day | Selected imported template | Exact literal/date instantiation in editable body | Unsupported expressions preserved |
| Manual edit | Existing Markdown with Unicode, CRLF, metadata | Edit at caret, preserve untouched bytes, local revision retained | Failed write retains editor content |
| Restart/navigation | Saved or pending body edits | Correct date and exact text restored | Failed persistence cannot silently lose edits on navigation |
| Concurrent source change | Disk differs from base | Retain both versions; explicit review/merge/retry | No overwrite by stale autosave |
| Interrupted save | Fail before/after atomic replace | Recover same revision idempotently, retain prior version | No false success or duplicate append |
| Legacy input/voice | Existing draft or confirmed insertion | Visible recovery path; original evidence retained | Unknown operations block conflicting writes |
| Voice from Today | Current document open | Preserve recording workflow; confirmed text reaches document without restoring old bottom composer | Source changes require renewed preview |
