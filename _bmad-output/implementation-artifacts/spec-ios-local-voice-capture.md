## Intent

**Problem:** Voice input and recovered recordings are missing.

**Approach:** Add microphone capture, pause/resume/end/replay, available on-device Chinese transcription, correction and explicit draft insertion followed by ordinary Save.

## Boundaries & Constraints

**Always:** Bind day, exact selected raw heading and storage namespace before permission. Ask microphone permission only after record action; ask Speech permission only on transcription. Preserve original audio until separate confirmed deletion. Retain original/corrected transcripts; retries never replace later corrections. One insertion per recording; preserve draft text and saved bytes. Retain data; sanitize errors. Recovery never restarts the microphone. Missing on-device capability is an honest unavailable result. Use only synthetic test data and the existing Simulator.

**Never:** No online audio fallback, Air/backend change, real-vault migration, ambient recording during automated tests, AI polishing, general diary-body overwrite, new account assumptions or claims of physical-device acceptance. No recursive skills/subagents.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|---|---|---|---|
| Permission | Denied, unavailable, cancelled or late response | No obsolete recorder starts; typing/settings remain available | Preserve input and target |
| Recording | Rotation, pause, interruption/route loss, resume, crash | Unique segments; explicit resume; actual duration and last playable piece shown | Keep completed and incomplete originals; never claim zero loss |
| Storage | Write/finalize failure, corrupt manifest, changed media | Same pending action can recover; valid records remain accessible | No overwrite, silent deletion or false success |
| Speech | Available local recognizer, missing assets, empty/error/cancel | Ordered source-bound proposals; original and corrected versions retained | Never upload; late/repeated callbacks cannot replace corrections |
| Insertion | Existing text, repeated request, lost result, later daily save | Exact preview appended once to captured draft; same identity survives receipt/cleanup | Reject stale source, mismatched payload and pending ordinary/workflow writes |
| Deletion | Audio export, confirmed delete, removal failure, late callback | Export original bytes; tombstone prevents resurrection; text remains | Retry exact removal; invalidate unapplied previews referencing deleted audio |
| Isolation | Midnight, another day, relaunch, sample/normal | Original destination and namespace retained | No cross-day or cross-namespace write |
| Compatibility | Old draft/receipt JSON and transaction retries | Absent optional fields remain absent; old hashes/after bytes unchanged | Existing local workflow regressions pass |
