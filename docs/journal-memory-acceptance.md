## 已发现并修正的问题

首轮真实模型遗漏了一个明确但日期未知的志愿经历；修改提取提示后，保留事件且日期为 null。第二轮两个公司的面试分别保存，但未建立 related 关系；补充区分不同事件的提示后复测建立关联。完整原始合成输出在 [评测目录](../evals/journal-memory/README.md)，这些用于调试的样本不能再当作盲测。

实现检查还修复了：成功写入但响应丢失导致重试、源变更后旧候选生效、撤权作废租约后不能继续、BOM private 头未解析、恢复关系 ID 未映射、超过 1000 条静默截断、整理故障影响普通检索，以及删除后关联说明残留的问题。相应失败路径纳入测试。
