通过既有 SSH alias 核验目标为 MacBook Air，交叉核对 Fleet、固定端口、进程工作目录、launchd 定义和 Mem0 Compose 标签。部署前备份将替换的源码、配置、服务定义及运行数据库，数据库备份均通过完整性检查。随后按精确清单同步 17 个源码/测试文件，不使用 `--delete`；全部 198 个运行时输入的哈希与开发机一致，依赖文件未变。
