## 新发现的阅读问题

**走查时发现：保存后的日记直接显示很长的内部来源 JSON、英文导师 ID 和讨论编号。** [冷启动后的原生截图](../../output/mentor-ux-walkthrough-2026-10-17/confirmed-screens/83007A04-1588-4ABB-A951-7821AE671836.png)显示这些记录占据 Notes 大量空间。数据完整性通过，阅读体验仍未达到要求。

建议后续将原始来源信息在正常阅读时折叠，默认只显示中文导师、讨论主题和日期；原 Markdown 和受保护来源仍保留，不能为隐藏界面内容而删除或改写记录。本轮走查记录此问题，未扩展修改日记渲染器。

同日后续已完成这项修正，并通过 64 条 Core、13 条 Native 与 2 条完整 UI 回归。详情及同一文件前后对比见[保存后 AI 建议的阅读体验修正](ios-ai-source-reading-2026-10-17.md)；以上段落保留为首次走查时的记录。
