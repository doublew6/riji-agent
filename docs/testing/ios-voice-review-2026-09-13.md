2026-09-13。本轮软件验证通过了 231 项 Core/State、13 项原生测试、12 条完整界面流程，共 256 项；通用 Simulator 构建及产物检查通过。随后独立审查发现以下待修复问题，语音实现仍在审查，不能按完整交付处理。

## 待修复问题

| 编号 | 用户可能遇到的问题 | 修复应达到的结果 |
|---|---|---|
| B1 | 新校正文件已写入，关联状态写入失败；重启后清理可能删除新文字 | 可发现并恢复失败写入留下的校正，确认已被替代后才清理 |
| B2 | 汇总转写原稿已写入，登记失败后无法从历史中找到 | 分批发现并恢复准确原稿，保留来源 |
| B3 / E2 | 采用刚刚变得不可读的历史原稿后，编辑器可能无法关闭或切换 | 采用失败不替换可用校正，输入和导航可继续使用 |
| B4 | 空间不足等原因使派生索引写失败，可读录音也无法进入列表 | 已读出的有效记录仍能展示，索引维护可重试 |
| B5 | 一份音频副本无法删除，后面的可删除原件也一直留下 | 独立清理可以继续，逐项保留失败与待重试状态 |
| B6 | 录音增多后，启动时同步扫描和刷盘空缓存目录越来越多 | 清理分批进行，今天的日记及时可用 |
| B10 | 长录音的全部片段反复连续核验，拖延保存和取消 | 分批核验并允许取消，继续保证确认对应准确原件 |
| B7 | 连续编辑校正时积压重复保存任务 | 合并过时任务，保留正在写入与最新文字 |
| B8 / E1 | 未完成录音的证据文件损坏，阻断全部转写或插入 | 此段显示完整性未知，其余原件仍可用 |
| B9 | 损坏的超大时长汇总后使整个列表编码失败 | 隔离异常记录，其余列表正常显示 |
| G1 | 实际录音面板的“结束”按钮接线缺少完整行为测试 | 点实际按钮后持久化结束；重开不能继续，暂停则可继续 |
| G2 | 本机识别始终不返回时，超时清理没有直接测试 | 实际超时释放请求和副本，可重试，旧回调不影响新请求 |

前七项需要完善恢复或处理流程；后五项是局部修正与测试补充。14 条审查发现逐条判定后合为 12 个独立问题，详情与证据在[语音规格](../../_bmad-output/implementation-artifacts/spec-ios-local-voice-capture.md)的 Loop 5 formal review。此前通过的测试和精确源码快照均已保留，尚未撤回或重新推导代码。

本轮触发 bmad-build 审查流程的第 6 轮暂停条件，等待用户明确允许突破轮次限制后继续。当前代码未提交或推送。本轮最后的只读核验确认：先前记录的两份正常/示例日记及草稿字节均保持不变；所有测试与构建已结束。
