## 本轮行为

| 使用场景 | 改后的行为 |
|---|---|
| 阅读群聊或旧圆桌 | 普通消息不显示勾选圈。长按或消息更多可复制、保存到日记、多选；只有主动多选才出现选中状态及取消。复制包含条件、分歧及下一步。 |
| 选多条建议 | 同一轮最多五段，超限或跨轮保留原选择并说明；选中状态可由辅助功能读出。 |
| 保存到日记 | 自动准备一份预览；修改文字时就地切换编辑区，完成编辑后重新核验。正文、日期、来源、AI 性质与是否编辑清楚可见；确切 Markdown 可展开核对。仍需明确确认才追加。 |
| 暂不保存 | 完成可保留已准备预览后离开；尚未保留的修改须明确继续或放弃。取消保存只在核对后安全释放本地预览，未知结果与已写入内容不会被假称撤销。 |
| 连续聊天 | 私聊、群聊和旧圆桌发送不主动收起输入焦点；已有独立草稿、阅读位置及新回复入口保持。 |
| 改群名 | 群详情点名称进入独立取消/保存页。未改、空白或超长不能保存；成功返回群详情。未知请求保留原 ID 和文字，可稍后处理。 |
| 连接与回执 | 凭据存在与服务在线分别判断；离线、响应异常、授权失效及旧服务能力分开说明。普通聊天成功回执收起，记忆/资料使用等主动操作仍有完成反馈。 |

日记预览继续绑定确切内容、目标、来源版本及一次性操作。改字/日期立即使旧确认失效，迟到核验不能重新启用；重建失败保留旧预览，未知保存先只读核对。选择结果的入口只接受本次操作绑定的结果，不会回退到上次消息的验证结果。
