## 手机上完成首次确认

打开 **设置 → 通用 → VPN 与设备管理**，在开发者 App 中选择本人用于 Xcode 的 Apple 账号，按实际提示信任或验证。验证需要联网；若要求重启，重启后继续完成提示。随后从主屏幕打开 Riji。

这与数据线连接时的“信任此电脑”、开发者模式是不同步骤。后两者已通过实际设备信息确认，不需要反复配对或重置设置。[Apple 的设备信任入口说明](https://support.apple.com/zh-cn/118254)及[适用于免费开发者账号的信任控制](https://developer.apple.com/documentation/devicemanagement/restrictions)。

## 开始使用

手机是独立的新安装，模拟器中的个人模板、配置和日记不会自动搬过来。在底部 **设置 → 日 / 周 / 月模板与星期语言 → 从文件选择模板** 导入原模板，再选择 **使用此模板**。在日记左上角目录选择本人手机“文件”中可见的原目录。

当前版本的正文保存到 App 本地空间，外部目录支持只读浏览；iCloud 原位写入、Air 导师与记忆还未接入。安装和启动检查不代替真实录音、后台中断、中文识别、原目录写入与跨设备冲突验收。
