# iOS 个人 MVP：目标验收清单

更新：2026-09-15。依据[PRD v3.0](../PRD.md)及[开发计划](../product/ios-personal-mvp-development-plan.md)。产品/交互已确认，本页是后续实现目标，所有项初始未勾选；现有可操作版本仍看[当前手动指南](ios-manual-acceptance.md)。

每条完成记录至少包含：工作包、版本、日期、设备/系统、合成数据范围、操作、预期/实得和证据位置。私人内容和绝对库路径仅保存在本机忽略输出。自动测试、Mac 手动、真实 iPhone、Air 与模型分别标记，不用一种证据替代另一种。

## A. 日记与设置（01–03）

- [ ] 打开 App 直接到今天的原日记；原模板的标题、清单、表格、自省与学习栏目完整，未出现替代模板。
- [ ] 点任意正文位置输入和修改，勾选任务、撤销，收起键盘后排版保留；无独立输入框、区块选择或逐段保存。重开后保存内容一致。
- [ ] 在今天手指从左向右滑动进入昨天，再从右向左滑动回到今天并进入后一天；日期选择及回到今天仍可用。跨年、闰日、DST 和本地跳日按相邻日历标签切换；0001/9999 年越界留在原日。每篇内容与光标/阅读位置独立保留。
- [ ] 上下滑只滚动；文字选区、光标拖动、中文输入法候选与表格横滚不误切日期。快速连续手势不把两天内容混写。
- [ ] 保存失败/冲突未处理时双向滑动均不会先换日期或丢字，能在原文重试或恢复。浏览缺失或未来日期只显示原模板，不创建空日记，也不跳到最近已有文件。
- [ ] **设置与日记、导师、记忆在底部并列，为第四个主入口。** 目录不另设设置栏；设置根页用底部切换，子页用返回，没有递归的“更多”。切回日记保持原文与阅读位置，保存失败不能丢失输入。
- [ ] 四个主入口依次为日记、导师、记忆、设置；文档操作和设置不混用。大字体、VoiceOver、较窄屏幕与键盘遮挡检查通过。
- [ ] 原目录授权可恢复，取消重选不清空连接；缺权限、文件未下载、目录移动有可恢复状态，不拿空文件覆盖原件。
- [ ] 支持的库内链接和本地附件可显示/打开；相对引用保留，缺失、未下载或不支持类型有提示，不能越过已授权目录。

## B. 同一 iCloud 文件与恢复（01、03）

- [ ] 在专用合成测试库中，手机修改的就是 Mac Obsidian 打开的同一相对路径文件；两端依次修改后可看见一致内容，无另一套 App/Air 日记同步。
- [ ] 无本机未保存编辑时外部更新刷新；双方同时修改先保留基准与可用两版，再比较/选用/合并，稍后处理保留文字；目标再次变化时重新核对。
- [ ] 离线编辑已下载文件、同日并发新建、后台离开、异常退出、受控空间不足和未知写入结果分别有恢复证据；保存成功后不丢失，重试不重复追加。
- [ ] 外部删除使来源失效；未同步编辑保留为冲突，不自动复活原文件。未改动字节、未知属性、链接、附件与 AI 来源标记保留。
- [ ] 旧 App 沙盒里的日记、录音和恢复记录仍在；切换原目录不自动覆盖或丢弃独有内容。

## C. 本人 Air 连接（04）

- [ ] 核验本人身份、原记忆 owner 与设备；模型密钥/Review token 不下发，失效设备和错误身份被拒绝，旧队列不绕过撤销。
- [ ] 真机在选定网络场景访问正确的 Air 服务；开发机 loopback 隧道没有被当成手机地址。
- [ ] Air 离线时本地日记可继续写；联网重验请求及权限。已发、未发、未知结果、取消与重试分别有正确状态。
- [ ] 本机保存、iCloud 传播、Air 读取、AI 生成与记忆生效不共用一个成功状态。

## D. 原日常工作流（05–06）

- [ ] 原日/周/月模板、日期变量、文件名、北极星指标/口径及已有自动填充规则均逐项核对，无硬编码的个人模板或虚构指标。
- [ ] 根据本人指标给出一个可修改 MIT，确认后是唯一当前计划；实际反馈区分完成/部分/未做，建议、采纳和执行不混淆。
- [ ] 正文修改 MIT 或旧反馈后能核对与确认记录的差异；无关段落不误报，旧历史差异不使完整新计划失效。
- [ ] 周记/月记名称、原模板结构和原目录正确；生成有精确周期、来源/缺口、原位校正、确认和保存回执，既有文件和本人修改保留。
- [ ] 跨月周、年界、闰年、当前未结束周期、来源缺失/排除及重复证据不造成错周期、虚构数值或重复计数。
- [ ] Air 原任务真实规则、时区、确认方式与结果已核验；App 接入不重复装任务、不默改写入策略，漏跑与未知结果按原操作处理。
- [ ] 真实 MIT/周记/月记生成前，Air 已读取同一 iCloud 来源版本；源未就绪时不假称使用最新日记。
- [ ] 在设置中手动运行、启停或修改任务时间，Air 确认后才显示生效；失败/未知回执不重复执行。本人可配置每日 MIT 生成，未配置不自动启用，已有任务不重复创建。

## E. 记忆（07）

- [ ] 新建手机日记与修改后版本分别经 iCloud 到 Air，按既有授权形成有正确来源的新记忆，并能被导师正确使用。
- [ ] 共享事实、导师私有观察、待复核项、原文依据和失效/未下载状态正确；推断不自动升级为本人事实或模型可用共享内容。
- [ ] 纠正/复核/归档/恢复与删除各自保留正确历史；删除保留原日记并阻止同一来源版本重建，派生/缓存/待发负载按规则失效。
- [ ] 四用途、private/local/none、接收方和预算不因手机接入放宽；离线撤权明确等待 Air 确认，已有模型请求不假称撤回。
- [ ] 进度和覆盖是真实发现/成功/排除/待处理/失败，不以条数冒充完成率；暂停/继续和失败重试不无限新增任务。

## F. 导师与圆桌（08–09）

- [ ] 点四导师中的任意一位直接聊天，不建问题/话题；切换并回来后历史、草稿和待回复状态各自保留，连续三次续聊不串导师。
- [ ] App/飞书历史关系有实际验证，不把共享记忆说成已导入全部历史；自动捕获未验收时明确关闭。
- [ ] 点圆桌直接输入并收到主持回应，按需邀请导师；没有标题或背景表单，结果后继续同一聊天。
- [ ] 材料预览与真实接收范围一致，发言者数量不改变实际共享成员；未授权日记/记忆不入桌，来源变更/撤权使派生失效。
- [ ] 参考不自动升级辩论，只有真实分歧才交锋；轮次、同次预算、部分结果、停止、迟到回复、重连恢复与未知结果逐项检查。
- [ ] AI 讨论保存有实际目标/内容预览和唯一回执；显示、导出、检索、记忆中持续保留 AI 性质，不能被当作本人已完成经历。

## G. 完整验收与语音条件项（10–11）

- [ ] 导出范围清单准确，包含所选 Markdown/适用附件、只读讨论、记忆快照/结构化导出；取消不改原文件。
- [ ] 恢复包预检格式、范围、冲突和删除抑制；不覆盖原件、不恢复活跃凭据/失效授权、不启动模型或自动重建已删除记忆。
- [ ] 清缓存只处理可重取副本，不删除唯一或未同步原稿；异常恢复记录保留，完好正文仍可只读查看/导出并说明限度。
- [ ] 旧 App 数据、飞书、Hermes、Memory Review、导师隔离和原任务完成相关回归；Air 按备份/验证/受控更新流程验收。
- [ ] 记录机型、系统与文档规模，测量打开/保存响应、后台离开及较大文档输入；达不到目标先说明实测限制。
- [ ] 条件项：免费键盘听写在本人手机测试中文、标点、正文位置、校正、保存；不可用则记录“暂缓语音”，本项不阻挡文字版。
- [ ] 条件项：独立录音若交付，权限、中断/锁屏/来电、回放、原音频保留、晚到结果和恢复全部通过；否则不作为正常可用功能交付。
- [ ] 本人试用能顺畅记录、回看周记/月记、使用 MIT、续聊和修正记忆；问题按影响记录并回归，不以模型调用量衡量完成。
