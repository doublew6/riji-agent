# 常驻导师问题开发与验证记录

日期：2026-09-11。对应 [PRD v0.3](product/PRD-persistent-mentor-roundtable.md)、[技术设计](architecture/persistent-mentor-roundtable.md)及 [Issue #43](https://github.com/doublew6/riji-agent/issues/43)。

**当前状态：Air 已部署，生产飞书常驻群仍受能力门禁限制。** 本文保留本地业务、页面和保存链路的开发验证证据；后续 Air 升级及真实模型隔离样本见[部署验收记录](persistent-mentor-roundtable-air-2026-09-11.md)。生产群及完整模型质量尚未通过验收，四位机器人以前能发言的证据不替代此次长期群能力验收。

## 1. 本轮变更

- 同一个长期问题保留原群，支持多次独立、有上限的参考/辩论；参考继续辩论复用原额度。
- 日记导师默认接话、单导师插问、显式新场次、停止、归档恢复；暂停的完整讨论恢复原额度。
- 工作背景按来源保留版本，支持原话纠正、计划/反馈类型、重新分析和历史回溯。
- 管理页展示摘要更新时间/覆盖范围、场次、本次与累计用量；允许选择同一场次的结果并转交保存。
- AI 结果在 Notes 内单独标记；本人私聊预览、改稿、换日期和确认。新稿使旧确认失效，不覆盖已保存日记。
- 来源类型贯穿索引/切片/检索/记忆提取。普通个人回顾默认不读 AI 结果；明确读取后的派生回答带类型，不能再经普通草稿或跨轮历史改成“本人经历”。
- 跨问题转交随原来源纠正、撤回或删除失效；重新分析也过滤转交背景中的 AI、混合及不明内容。保存事务和原子写入前再次核验来源。
- 飞书只读群证据收集和主持人事件规范化；未打开缺少证据的生产群入口。

本地开发验证阶段未修改生产凭据、运行配置、真实日记、记忆数据库、飞书应用或群，未创建新后台服务、占用项目端口或向飞书发送测试消息。后续部署动作单独记录，不改写本节测试范围。

## 4. 明确限制与下一步

1. 工作摘要是有界来源摘录，48 条/18,000 字符到限后要求用户明确整理背景。它能刷新版本和纠正来源，但不是自动语义压缩，不能宣称长时间无限续聊已验证。
2. 自然群文字默认保留为本人原话，不自动把关键词识别为已执行事实；页面支持明确计划/反馈类型，真实自然语言质量仍要验收。
3. 飞书缺少足以证明新成员历史可见性和断连期间成员变化完整性的证据。只读探针不提供人工放行开关，`complete/history_restricted/continuity_verified/management_restricted` 等未证明项保持不满足。
4. 原日记导师仍由 Hermes 独占接收。普通群功能需要受控桥接或有序迁移接收权，不能并行启动相同应用的长连接或放宽旧私聊 Gateway。
5. Air 备份、源码同步、远端测试及主服务升级检查已经完成，见[部署记录](persistent-mentor-roundtable-air-2026-09-11.md)。仍须通过真实群、手机及完整模型质量验收，才能宣称 PRD 的生产群功能交付。
