## 2. 这版的共同设计

- **写日记像打开自己的文档。** 主界面直接是今天正文，不新增欢迎仪表盘、独立输入框、区块选择或保存按钮。模板标题、Emoji、字段和顺序由用户原文件决定。
- **记忆像一份会更新的认识目录。** 先看到变化与具体主题，再下钻到来源。不开三维图谱，不把原始记忆条目铺满首页，不把固定六类当唯一目录。
- **设置像工具抽屉。** 首页只保留可理解的分组和当前值。AI 配置、用途、任务细节放在子页，服务失联不会阻挡日记编辑。
- 三个区域使用 `docs/DESIGN.md` 的奶油纸底、深灰绿正文、低饱和深绿操作色；导师保留自己的局部深色。四个底部入口并列且顺序不变。
- 系统字体、16–17 pt 正文、20–24 pt 页边距、至少 44 pt 触控目标；连续文档不逐段装卡片。深色仅切换语义色，长文本和大字号优先重排。
- 正常保存安静完成。只在未保存、需核对版本或来源不可用时提供具体入口；不恢复常驻“已保存在此设备”大框，不声称所有设备已同步。

| M05 | 待我判断：单项结构建议、双方依据和影响；接受、保持分开或稍后 | 记忆演化 FR-07、09、26 |

日记周／月记（D05）是原目录里的文档；记忆周复盘（M04）是 Air 派生的记忆报告。两个入口、对象与保存动作明确区分，不改成一份重复计数的经历。

北极星定义仍来自本人原定义。导师页关联的只读段落与 D04 的当前目标版本不能默默混用；来源不一致时显示来源并要求选择，不因页面统一就改写另一份目标。

## 4. 异常与小屏设计

| 状态 | 展示与动作 |
| --- | --- |
| 第一次打开／目录失效 | D01 就地“打开原日记文件夹”；取消保留原状态，旧 App 文件从设置恢复 |
| 文件未下载 | 显示等待下载与重试；不使用空正文覆盖文件 |
| 外部更新，无本机未保存编辑 | 刷新正文并保留可恢复的阅读位置，不弹比较页 |
| 真正重叠修改 | D07 只呈现需要判断的片段；未改段落折叠为上下文；双方可恢复，未知结果先核对 |
| 离线记忆 | 明确标注最近核验时间；只读有效本机副本，纠正保留草稿，联网重验后提交 |
| 依据或授权失效 | 撤下旧摘要、名称及派生片段，显示待更新；不能用离线副本补回已知撤回内容 |
| 未整理／无新增／部分完成 | 分别说明，不以空白卡片或“全部完成”替代；保留旧分类过渡入口 |
| 服务不可用 | 日记正常；AI 页面显示重试或本机草稿，设置中查看连接详情 |
| 发送／写入结果未知 | 保留原请求，先核对，不把重试画成再新建一次 |
| 大字号／键盘 | 单列阅读、文字换行、动作置于安全区；编辑时键盘附件只承载正文工具，收起后恢复四项导航 |

## 5. 原型能做什么

18 屏包含屏间跳转、四入口导航示意、浅／深色切换、正文与表格编辑、日期选择、主题时间线切换、纠正前后比较、冲突选择、任务编辑、权限变更比较和导出恢复步骤。页面旁边的意见可暂存在本浏览器，并导出 JSON／Markdown；有存储失败时仍允许导出。

全部日记、目标、记忆、目录及时间是**合成示例**。交互只改变原型中的示例状态，不访问日记目录、iCloud、Air 或模型，不发送反馈。除评审意见以外，示例修改仅保留在当前页面会话；不冒充真实自动保存、真实任务运行或功能已经完成。原生键盘、系统文件选择器、滚动与编辑手势需要后续真机验收。

历史原型涉及私人模板，本轮没有把其原文复制进新稿，也未调用外部设计服务。可见的模板块只是展示连续正文的合成片段，不成为 App 默认模板。

## 6. 已确认与实施边界

18 屏布局及 D01/M01/S01 的信息密度已确认，不再等待布局评审。后续新页面先沿用本版信息层级与 `ApprovedPageStyle.swift` 共用原生组件；平台动态字号、系统选择器及长文本允许自然重排，示意画板尺寸不写入应用。

本地原生实施使用 #53–57 已存在的能力。#58 仍为 in-review，已知缺陷未解决，不合并或启用其未核验实现。记忆首页的“最近”准确称为**已下载依据更新**；主题来自 #57 的真实 `themeSummaries`，六类仅作筛选和深层旧入口。未知覆盖始终注明不足。导师另行确认的 F v1.0 保留，新的导师交互讨论稿不在本次范围。
