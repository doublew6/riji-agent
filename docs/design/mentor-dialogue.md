# 导师对话设计确认 — F · 北极星指引

**当前生效版本：v1.0。确认日期：2026-10-12。** 用户在本次设计对话明确表示：“这个设计，我认可”。确认对象是 2026-09-27 出稿的 **F · 北极星指引版**，包含多导师圆桌与单导师对话两屏。

本文件保存已确认的页面视觉与设计意图。2026-10-13 已完成对应原生 iOS 实现与专用模拟器验证，2026-10-14 已完成用户授权的真机安装与启动检查；真实使用体验仍单独验收。视觉基线保持 v1.0，以下实现记录不把未经用户评审的交互细节追认为新的设计确认。


**2026-10-17 最新交互确认：** 用户明确答复“是，在导师首页直接聊天，不跳页面”。上方保留北极星与四位导师人物，点人物仍进入该导师的固定私聊；下方直接显示当前群的消息与输入框，通过群切换控件原位切换，同时只显示一个活跃群。创建后在首页显示新群；群详情、改名、归档和恢复作为辅助操作。键盘弹出或使用较大字号时收紧上方人物区，优先保证消息、群切换和输入可操作。旧圆桌同样在首页显示，原记录身份、成员与接收范围不变。此确认覆盖 2026-10-16 “首页点群后进入聊天页”的解释；F 的气质、人物、暖光和北极星含义仍为 v1.0。本次已实现并通过本轮本机回归，待用户体验确认；真实服务与真机安装另行验收。

## 1. 已确认的设计

| 方面 | 确认结论 |
| --- | --- |
| 整体气质 | 空灵、宇宙感、超越时空，同时保留温度和亲近感。 |
| 色彩与亮度 | 沿用 F 的沉静深色方向，以低饱和深绿灰为主；背景光、星体与圆环保持克制，人物有柔和暖光。 |
| 多导师圆桌 | 手机上部呈现空间圆桌与导师关系，下部采用游戏多人对话式的发言者、人物和对白组织。 |
| 单导师对话 | 与圆桌保持同一套空间、人物和对白语言，突出当前导师的陪伴感。 |
| 未来的我 | 使用用户提供形象衍生的男性形象；保留短发、眼镜等识别特征，不再沿用早期女性占位形象。 |
| 北极星的意义 | 代表用户当前中期或阶段目标，承担方向指引作用；可以随阶段调整。 |
| 北极星的表达 | 上方一颗清晰而克制的引导星，邻近展示阶段目标；圆桌和单导师两屏保持一致。 |
| 对话关系 | 导师可以帮助用户把当下选择、行动与阶段方向联系起来。 |
| 字体与控件 | 现代系统无衬线字体、安静的深绿控件、清晰对白；沿用全局导航及通用组件规则。 |

“建立稳定的创作节奏”与画面对白均为示例内容，不是用户已经设定的真实目标，也不是产品默认目标。

## 2. 与全局规范的关系

继续遵循[暖光书桌·沉静深绿视觉规范](../DESIGN.md)。导师对话局部采用该规范的深色参考色系，本次确认不改变日记、记忆、设置等页面的浅色默认基线。

宇宙场景、圆桌和人物是本页面经用户要求并确认的视觉表达，集中服务于上方对话场景。正文、输入与操作区保持安静和可读，不把整套应用扩展为宇宙主题。

色值、字体、尺寸、无障碍与动效通则从全局规范引用，不在本文件维护第二份 Design Tokens。生成图用于表达视觉目标，具体像素并非实现规范。

## 3. 实现记录与待验证事项

2026-10-13 按用户“按照这个设计规范开始开发”的指令完成本地开发：

- 单导师采用居中的男性眼镜人物，圆桌显示四位导师与实际参与状态；最新导师对白采用文字与人物并排，较窄宽度或无障碍字号改用纵向。页面保留完整对话历史，场景随历史滚动。
- 北极星入口支持查看完整内容、预览确认、重选和取消本机关联。用户明确选择本地目标当前版本，或已授权原目录中的确切段落；未选择时只显示可选入口，不默认使用示例目标。
- 只在本机保存按来源和账户隔离的引用，排除设备备份。进入对话、返回前台及每 15 秒重读校验；来源变化或无法访问时撤下旧目标并给出恢复入口。不会改写原目标，也不会自动发送给导师。
- 键盘或无障碍字号优先让出人物空间。实际发言者及主持人切换使用 200 ms 指示线淡入/淡出，Reduce Motion 时直接切换；星空与圆桌没有持续旋转、闪烁或呼吸动画。
- 运行素材为透明四角色图集，未来的我沿用已确认的男性短发、圆框眼镜形象。完成原生截图与确认稿对照；日记等其他页面维持原外观。

完整测试清单、失败及修复证据、截图和已知限制保存在本地实施记录 `docs/testing/ios-mentor-north-star-2026-10-13.md`（不随本次设计文档发布）。604 项 package 测试通过；59 项 Native 和 8 条聚焦 UI 流程分轮通过。日常 smoke 已纳入三项新增导师 UI；本次未执行全量 smoke 或远程 CI。

2026-10-14 已在既有 iPhone 14 Pro 覆盖安装并正常启动；167 个 App 自有数据文件在安装前后数量、路径与哈希一致，详见本地安装记录 `docs/testing/ios-mentor-north-star-install-2026-10-14.md`（不随本次设计文档发布）。本次未更新 Air。

仍待单独验收：真实 iCloud 传播、真机较小屏幕、物理键盘/听写、VoiceOver 朗读和真实服务体验。切换目录授权根可能需要重选段落；进入后台会重置未确认的选择位置，已保存关联重新核验后恢复。

业务行为继续遵循[产品需求](../PRD.md)及最新已确认专项需求。本地尚未发布的交互草案不能通过本次设计文档归档视为获批。北极星沿用用户原定义、阶段和版本；页面展示不自动扩大资料分享范围。AI 建议、本人采纳和实际完成保持区分。

2026-10-14 用户体验后提出人物灰暗、导师选择不自然，以及记录和话题切换需要重审，要求暂停开发、先讨论新 PRD。视觉方向仍为 v1.0，既有实现不等于交互体验获验收。后续交互候选须另行确认；本次归档不包含该候选或应用代码。

## 5. 决策沿革

| 日期或顺序 | 记录 |
| --- | --- |
| 前期探索 | A/B/C 未被采用；“心灵剧场”更接近用户理念，随后明确空灵、宇宙感、超越时空但不冰冷，且“未来的我”为男性。 |
| 2026-09-24 | 在 D/E/F 中倾向 F，要求降低亮度，并对齐已确认的视觉规范；形成沉静版。 |
| 2026-09-27 | 用户明确北极星是中期或阶段目标，要求突出指引作用；形成当前双屏稿。 |
| 2026-10-12 | 用户明确认可当前设计，登记为导师对话视觉基线 v1.0。 |
| 2026-10-13 | 用户授权开发；完成原生单导师、圆桌与北极星关联，登记模拟器验证证据，视觉基线仍为 v1.0。 |
| 2026-10-14 | 用户授权并连接手机；完成覆盖安装、167 个数据文件完整性核验及正常启动，真实体验仍待本人验收。 |
| 2026-10-16 | 用户在模拟器中要求群直接列在首页，点入就是消息；移除群页重复的大人物场景，保留首页 F 视觉与旧记录。修正的实施和验收单独记录。 |
| 2026-10-17 | 用户明确“在导师首页直接聊天，不跳页面”：上方人物仍进入固定私聊，下方为一个当前群的消息与输入，群原位切换，键盘优先；覆盖此前群聊天页解释。设计已确认，已实现并通过本轮本机回归，待用户体验确认。 |

早期图稿保留为探索资料，不作为与本版本并列的实施选项。

2026-10-15，用户指出当前导师入口仍像默认黑灰列表，与此前绿色场景不一致，并明确同意补齐视觉。本轮修正导航容器中的背景、入口层级、静态场景深度、圆桌前后关系和对白承托；保留既有暖色人物、北极星来源与对话流程。新交互讨论稿未因此获批。功能回归和实际截图对照分开记录，先供 Mac 模拟器检查，不据代码完成声称手机已更新。详细证据保存在本地 `docs/testing/ios-visual-fidelity-2026-10-15.md`。

## 6. 保存与更新规则

1. 全局规范保存颜色、字体和通用组件；本文件保存该页面已确认的方向、适用范围和确认记录；版本目录保存图稿与来源材料。
2. 本文件的主稿保存在 Obsidian 项目 `design/mentor-dialogue.md`，仓库 `docs/design/mentor-dialogue.md` 是同版工程副本。版本、确认结论和正文同步维护，仅资料链接按各自位置调整。
3. 修改方案时新建候选稿和版本说明，保留旧确认稿；明确确认后再更新当前基线。不得直接覆盖唯一的已确认图片。
4. 每次更新记录日期、修改内容、确认依据，以及设计、实现、测试、部署各自的状态。
5. 后续任务从项目指南与全局设计规范进入本文件，不依赖聊天记录检索或临时剪贴板路径。
6. 仓库提交仅保存文档文本；包含个性化人物的图稿与生成提示词仍为本地归档。Git 发布、私人图稿备份、iCloud 同步和应用验收分别记录，互不替代。
