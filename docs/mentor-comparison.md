# 导师比较的归因契约

2026-09-11，Issue #46。适用于新生成的主持人 `comparison`；历史记录保留原文，
不重写旧成绩，也不把结构检查通过声明为内容正确。

## 比较依据

只有主持人比较阶段可以设置 `debate_needed`。独立首轮、质询、综合及追问阶段
必须保持该字段为 `null`，且不能生成 `comparison_findings`。旧独立首轮中可能存在
的布尔值在发送给后续模型时置空，旧存储内容保持原样。

比较阶段必须明确决定是否存在有依据的实际冲突，并可保存 0–2 个
`comparison_findings`。每项包含：

- `decision`：比较的同一项决定。
- `shared_condition`：两项主张适用的共同条件，不能发明用户未给出的约束。
- `stances`：两位不同导师在当前场次、当前输入版本的首轮发言 ID 与逐字引文。
- `relationship`：`compatible`（一致/兼容）、`complementary`（补充/条件备选）、
  `conflict`（共同条件下实际相斥）或 `uncertain`（尚无法判定）。
- `rationale`：该关系的理由；主张冲突时须说明具体不能同时成立的内容。

本地核验来源 ID、当前场次和输入版本、两位不同作者、引文是否逐字出现在相应
发言正文，以及双方 ID 是否也在 `source_refs`。`debate_needed=true` 必须至少对应
一项 `conflict`，反向也须一致。缺失证据、伪造/改写引文或判定不一致进入现有一次
修复流程，每次仍计入原请求预算；再次失败则中断，不发布这一比较，不新增无限重试。

`quote` 的唯一正文来源是按 `artifact_id` 找到的 `previous` 首轮发言的 `text` 字段。
引文必须是 JSON 解码后该字段中的连续原文，保留相关条件、标点和空格；不能从
`claims`、`next_steps` 或 `uncertainties` 复制，不能拼接不同段落或改写。某句话即使
确实出现在同一导师的行动项中，只要不在其 `text` 中，就不能作为此契约的引文。
比较提示和 `quote` schema description 都明确这一点。收到
`comparison_quote_unsupported` 时，现有一次修复会明确要求按 ID 从 `text` 重新选取
并逐项检查连续子串，再核对关系和条件；不注入失败回答正文、不放宽验证、不增加请求额度。

“双方推荐不同时间”并不必然是冲突。例如两位导师均建议先绑定晚间习惯，其中
一位补充“晚上持续失败后可改早上”，另一位没有反对早上，就是有条件的补充。
未提及一个选项不能当作反对证据。若双方在同一不可兼得的约束下分别明确主张
只选不同方案，则应保留冲突，交给本人质询。三位支持、一位反对时，少数立场仍可
作为配对依据，不能靠投票消除冲突。

## 内容验收仍是独立步骤

逐字引文只能证明归因可追溯，不能自动证明两项主张在语义上相斥。条件可能被
错误解释、引文可能遗漏限定语，正文也可能与结构字段不一致；这些必须检查实际
输出。代码没有使用关键词判别中文立场，也没有把同一模型自报的关系当作质量分数。

独立内容判据位于 [comparison-review.json](../evals/agent-v1/comparison-review.json)。
它与 target 输入分开封存，包含原回归题、无分歧题和真实冲突/少数观点控制判据。
复测使用新源码、新批次；首先检查机器契约，再逐项核对双方原话、条件、关系、正文
及后续综合。原题和无分歧题需真实模型重跑，并与明确相斥的控制样例比较，防止通过
一律关闭辩论取得表面改善。多个重复运行须分别保留，不能覆盖首次失败。

尚未进行真实模型复测时，只能报告离线契约测试通过，不能宣称误判已经稳定消失。
人工评分仍应独立保存；助手编写的判据不是独立盲测。

## 持久化与兼容

新比较证据随 `Artifact` 存储、进入后续可见上下文及导出；恢复只读档案时同步
重映射双方发言 ID。旧记录缺失新字段时默认空数组，仍可读取。
旧首轮发言缺少 `run_id` 时，仅在原始第一场 `initial`、相同问题和当前输入版本、
且不处于重新分析或挂起场次时可用于恢复后的比较；schema 与本地校验共用这一选择。
后续完整场次、追问、显式其他 `run_id`、其他问题或旧输入版本均不能借此带入。
旧待确认预览的空字段不改变摘要指纹；有新比较证据的预览把这些字段及布尔决定
纳入指纹，证据被修改后不能沿用旧确认。所有来源依赖、导师隔离、AI 来源标记和
日记确认规则继续由原服务执行。

已有旧比较不被自动重评或迁移；其缺失结构证据不能被当作完成了新契约验收。
