## 3. 自动测试与真实模型样本

Air 使用生产 runtime Python 运行全量测试：**1130 passed，10 skipped，105.11 秒**。跳过项为：4 项离线官方 Codex CLI 检查未设置 `RIJI_TEST_CODEX_BIN`，5 项可选 JSON Schema 检查未安装 `jsonschema`，1 项可选浏览器检查未配置运行时。没有测试失败；跳过项不计为通过。

开发机此前的完整结果为 **1135 passed，5 skipped**，并已单独通过包含真实 Chrome 的 9 项页面测试。具体命令、12 个浏览器交互检查及合成测试边界保留在[本地验证记录](persistent-mentor-roundtable-acceptance.md)，不将其记作生产浏览器端到端验收。

Air 上另以真实 Codex `gpt-5.6-terra` 完成一个虚构绘画问题的隔离样本，共 8 次模型调用。使用临时数据和 `LocalChannel`，经人工阅读输出后确认：

- 同一问题、同一房间完成两场参考讨论及主持人追问。
- 每周可用时间从 5 小时更正为 2 小时后，新回答依据新约束；明确计划仍表示为尚未执行。
- AI 结果经确认写入隔离日记，重复确认后仍只有一个独立结果 callout。
- 默认检索排除 AI 结果，明确引用讨论时保留其 AI 来源类型。

该结果只支持一个真实模型样本的语义检查。它没有验证完整辩论、真实用户问题、飞书群输入或正式日记写入，也未完成 PRD 要求的 5 个真实问题及用户质量评估。

## 4. 未开放的功能与下一步

生产飞书常驻群入口继续失败关闭：当前证据不能证明新成员历史可见性及断连期间成员变化的完整性，不能通过人工开关替代。原日记导师仍由 Hermes 持有接收权，新增群主持需要唯一连接上的受控桥接或有序迁移；不得并行建立同一应用的长连接。

后续验收仍包括受控群采用/新建、真实主持人输入、成员与历史权限、手机操作、真实私聊保存以及多问题辩论质量。旧群中机器人已经发言，不代表上述门槛已满足。工作摘要仍为有界来源摘录，48 条或 18,000 字符到限后需要用户整理，未实现自动语义压缩。

## 5. 回滚注意事项

新版本兼容读取旧记录，但旧代码不能完整读取新导师 JSON 字段及字典格式草稿。出现回滚需求时，应先保存升级后的快照，再按备份清单配套恢复源码和受影响数据库，不能只退源码。新增 SQLite 列本身为带默认值的兼容扩展，但旧代码不具备 AI 来源类型处理能力。

若升级后已经写入真实日记或确认记录，先核对新增写入与确认状态，不得直接用旧数据库覆盖后重新执行，避免丢失记录或重复追加。保留原备份，不删除记忆 volume；优先修复已定位的问题。旧的待确认稿需要重新预览时，继续遵守本人确认流程，不绕过版本校验。
