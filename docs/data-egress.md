# 数据出云边界

本文件明确哪些数据离开本机、哪些绝不离开。

## 绝不离开本机

- 完整日记 vault、原始 Markdown 文件、本地 SQLite（索引/记忆/草稿/审计）。
- 任何被标记 `private: true` 的日记内容。
- API Key、飞书凭据、Hermes 共享密钥（仅存在于本地 `.env` / 环境变量；不进日志、不进异常消息、不进审计）。
- 文件系统路径与 vault 目录结构（模型只见 `source_id`，见不到路径）。
- 本地 embedding 向量（启用语义检索 `RIJI_SEMANTIC_SEARCH=true` 时）：在本机生成与持久化，绝不出云；语义检索不调用任何云端向量服务。
- Mem0 PostgreSQL、FastEmbed 向量、`MEMORY.md`、捕获队列与记忆变更日志。

## 会离开本机（最小化）

| 去向 | 内容 | 约束 |
| --- | --- | --- |
| 飞书 | 用户消息与回复 | 仅白名单用户私聊；群聊禁用日记能力 |
| 配置的导师 provider：DeepSeek、OpenAI-compatible 或 OpenAI Codex/ChatGPT | 系统提示、用户问题、**检索工具返回的最小片段** | 片段条数/单段长度/总字数有上限；**永不含 private 内容**；按 `source_id` 引用 |
| 配置的记忆 provider：DeepSeek 或 OpenAI Codex/ChatGPT | 当前或授权回填的历史用户原话、原始消息时间 | 每次最多 8000 字符，逐条后台请求；不发送助手回复、日记检索片段或控制命令；日记记录请求中的自述可提取，但不代表已保存日记 |
| 配置的导师 provider，历史召回 | 同一用户、导师和聊天的历史用户原话片段 | `session_search` 每段最多 400 字符、合计 1500 字符；跳过凭据消息，返回时间与 `conversation/<id>` 来源 |
| 配置的记忆 provider，日记提取与整理 | 授权区块的有界原文、新候选及相关有效旧记忆、时间和依据标识 | 四种用途分别授权；来源/派生权限及片段/来源版本限制继续过滤；日常每日 100000 字符，本次明确授权的固定历史批次单独计量，初始处理及显式登记的一次整理恢复分别在终态关闭日总量豁免 |

## 强制点（代码层）

- 检索工具一律 `include_private=False`：private 日记不进搜索结果，`read_note` 对 private 二次拦截。
- `search_journal`/`timeline` 等对结果条数、单片段长度、总字数设上限。
- `read_note` 需先有同会话检索证据；工具只接受 `source_id`，无任意路径读取。
- 王阳明思想资料库与日记**分库分流**：思想引文与日记事实在工具结果中分列，互不串源。
- DeepSeek Provider 仅把 Key 放进 Authorization 头；HTTP 错误消息不含 Key。
- 审计只记录元数据：工具名、来源 `source_id`、结果状态、时间——不记内容、不记 Key。
- Agent 长期记忆使用本地 Mem0 与 FastEmbed；riji-agent 只向配置的记忆 provider 逐条发送符合条件的用户原话做结构化提取，再以 `infer=false` 写入本地 Mem0。历史回填必须显式运行 `memory backfill --apply`；默认统计不调用模型。
- 未启用日记记忆的既有主动整理会另向配置的记忆 provider 发送已保存的有界事实片段：每次最多 100 条，单批最多 20 条、6,000 字符正文，单条最多 2,000 字符。不同用户、共享事实和每位导师私有观察严格分批；不附带原始日记或完整会话。SQLite 运行记录在调用前保存批次来源 ID 与版本哈希，成功后保存摘要及证据引用。失败也保留输入清单，错误中不包含正文。比较与摘要只是建议，不自动覆盖 Mem0 事实。
- 启用日记记忆后，指定区块的片段可主动发送给配置的提取模型，不必等待用户提问。默认每片段 900 字符，同一文件版本累计原文 4000 字符，日常每 UTC 日 100000 字符请求正文。关系判断可带最多 12 条有效旧事实；新整理路径每轮最多 5 个种子，每种子最多 12 条事实、4500 字符事实正文。提示词和旧事实计入额度，原生聊天仍使用自己的既有边界。来源 ID / 版本和阶段在调用前写入 `journal-memory.sqlite3` 的 `egress_attempts`，不保存出云正文；同一库的恢复缓存可能暂存提取结果和证据引用，完成、撤权或删除时清理。详见 [日记长期记忆](journal-memory.md)。
- 用户于 2026-09-09 明确授权本次固定历史批次不设每日总量上限，取代旧每日 40000 字符策略。先扫描、登记新预算历史授权，再冻结已授权证据 ID / 版本与当前有效版本的交集；空授权后出现的文件不能自动纳入，后续授权、扫描、重试不扩充已冻结批次。其提取、关系判断及以本批产出记忆为种子的必要有界整理使用独立 `initialization:UTC-day` 计量，旧日账本不清零或追溯转移；新文件、新版本、普通整理仍用日常预算。提取终态且必要整理完成后持久关闭豁免，配置保持开启也不能重开。用户于 2026-09-10 进一步确认：本固定批次按失败 ID / 版本显式登记的一次整理恢复也按初始化账本计量，无每日总量上限；配置须保持启用、当前范围须与冻结范围匹配，且有首次发送与未消费恢复记录。有限恢复不重新开放原批次，不扩充清单，恢复已发送后不能再次领取；成功或失败后关闭对应例外。旧请求不清零、不追溯转移账本，普通整理和日常增量仍限额。此例外不改变单片段/来源版本上限、private/local/none 排除、四种用途或实际发送前校验，不授权一次上传完整原文。

## 可证明性

`tests/test_e2e_acceptance.py::test_private_content_never_egresses` 端到端断言：标记 private 的日记其 `source_id` 不出现在审计来源中，其正文不出现在发往模型的任何消息里，且对其 `read_note` 被拦截。

## 2026-09-09：显式日记授权与三级内容权限

参见 [PRD 隐私权限与数据流增量](PRD.md#15-隐私权限与数据流增量2026-09-09v13)。Memory Review 每页顶部展示当前状态和权限入口；历史、增量、整理、召回分别授权。整篇 `memory: none/local/cloud` 和局部 `riji-memory` 标记同时约束提取与旧检索路径，单条记忆可另设权限。仅本地内容不调用云端提取，当前没有本地生成模型。

保存授权绑定当前来源、版本范围、模型接收方和预算；配置变化后重新授权。暂停停止日记提取与整理；撤回同时停止日记派生记忆的新云端使用。原生聊天与原有受限问答是独立数据流，仍受来源私密标记约束。旧请求和用户独立备份无法由此撤回。

## 2026-09-09：Codex 可选接收方

选择 `RIJI_MODEL_PROVIDER=codex` 或 `RIJI_MEMORY_MODEL_PROVIDER=codex` 时，相应内容发送至 **OpenAI · Codex / ChatGPT（chatgpt.com）**，使用用户自己的 ChatGPT 登录。套餐计费与本地保存都不等于本地推理。提取和回答分别展示实际 provider、模型和接收方，任何相关变更都要登记新的日记授权，不能复用旧 DeepSeek 授权。

官方 `codex exec` 管理凭据认证与刷新；项目使用专属持久 `RIJI_CODEX_HOME` 完成一次独立官方登录，不复用个人全局配置，不提取、复制、链接或记录 token，不把它放进模型上下文。Codex 使用独立临时上下文，不继承用户个人任务和其他导师历史；通用文件、Shell、浏览、skills、hooks 和外部连接器能力禁用，只有本地代码能执行项目注册的受限工具。

临时上下文不表示云端零留存。ChatGPT 账号的数据控制适用于此认证方式，不能借用 API 的留存或训练承诺。额度和认证失败不会自动转向另一家服务商；本地任务暂停或退避后恢复。配置和验收门槛见 [Codex 接入说明](codex-provider.md)。
