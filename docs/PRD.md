# Riji iOS 产品需求文档

**本轮交付：供用户走查的 iOS 产品设计与低保真全流程图，尚未实现。** 打开 App 直接进入今天的日记。日记文件保存在手机；智能能力由产品统一提供，Air 是当前维护者管理的后台运行主机，普通用户不用知道或配置它。本文重写产品主线，不代表旧服务已迁移或新权限已启用。

[打开低保真全流程图](product/ios-design-2026-09-12/wireframe-riji-ios.html) · [原 PRD 完整基线](PRD-feishu-baseline-2026-09-12.md) · [近期进展与证据](product/ios-design-2026-09-12/progress-extract.md) · [技术补充与方案边界](product/ios-design-2026-09-12/addendum.md)

> **数据说明按需出现：** 文字和录音先保存在此 iPhone。启用同步会把所选文件发送到产品服务；使用智能功能会把获准内容交给服务及实际模型提供方处理。对其他下载者，维护者的 Air 属于远端服务，不是其自有本地设备。首次相关操作说明范围，详情在隐私设置可见，不在日记正文反复展示部署说明。隐藏的是配置与运维细节，处理去向和用户控制仍可查看。

## 1. 产品目标与范围

把沿用原模板的每日计划与记录、周月复盘、北极星指标下的每日最重要的一件事、个人记忆和持续请教导师放进一个手机 App。用户应能在没有网络时先把内容留下，在有需要时请 AI 整理或讨论，并随时看清“我说过什么、AI 建议了什么、系统记住了什么”。

**本次用户已明确的方向：** iOS 手机 App；本地文件体验类似 Obsidian；包含长期记忆、日记展示、语音写日记、单导师与多导师互动；Air 承接后端与 AI 调度。用户于本轮反馈进一步明确：原日记系统的模板建日记、周报、月报及“北极星指标 → 每日最重要的一件事（MIT）”必须保留，均为首版必需，不能降为后续扩展。

**本轮已确认的体验方向：** 服务地址和模型由产品维护者预先配置；正常启动直接打开今天的日记，不经过欢迎、配对、模板选择或 AI 配置向导。其他下载者使用同一产品服务，但各账号的资料必须独立。

**设计默认：** [A1] 产品统一提供后台能力，当前先服务已有用户；对其他账号开放前通过隔离验收。[A2] iPhone 保留本地 Markdown，启用同步后使用账号独立的服务端副本。[A3] 用户可以手动修改已有日记正文，但必须保留版本与冲突处理，这是一项新增写入设计，不改变 AI 的受限追加规则。未确认的默认集中列于第 10 节。

首版包括：开箱即用的今日日记、按需登录产品账号、沿用日/周/月模板、新建每日日记、北极星指标与每日 MIT、周报月报及其既有自动化迁移、离线记录与阅读、录音转写、日记确认保存、同步与冲突处理、固定导师私聊、持续问题圆桌、长期记忆管理、权限管理及本地导出恢复。首版不包含多人共享同一日记库、公开社区、收费导师商店、任意 Obsidian 插件兼容、手机上的完整推理引擎，以及跨设备无条件实时同步。

## 3. 使用方式与信息结构

**默认页就是今天的日记正文**，参考 Obsidian 的日期笔记与就地编辑方式。顶部只放日期、日记目录与更多；正文沿用原模板；底部固定一个“写一点…”输入入口和麦克风。已有今日 MIT 在原区块展示，不在首页放一排功能卡或大按钮。

底部常驻 **日记、导师、记忆**，取消单独的“记录”导航页。日期切换、周/月报、北极星和搜索放在日记目录；账号、同步、隐私及偏好放在更多 → 设置。服务器地址、配对、Tailscale 和模型配置只在维护者可见的高级连接页，普通用户不需要进入。

常用路径只有：**打开就是今天 → 在页内打字或点麦克风 → 留在当前日记查看结果**。直接输入的原文在页内显示目标位置并用一次“保存这段”确认；AI 整理的变动用同页底部预览确认；过期或来源/权限变化时也需刷新核对。原型中的输入、录音、转写、保存中和完成是同一个日记页的状态或弹层，不代表必须依次经过多页向导。

| 名称 | 用户含义与边界 |
| --- | --- |
| 本地记录 | 已保存在 iPhone 的文字或录音；不等于写入 Air，也不等于形成记忆 |
| 我的日记 | 本人写下或明确确认的日记内容；沿用原日模板，Markdown 可导出 |
| 周报 / 月报 | 按原周/月模板生成的周期复盘，保留时间范围、原始依据、AI 分析与本人补充，不等于新增一次经历 |
| 北极星指标 | 本人确认的长期方向、指标口径、目标和当前阶段；不由模型自行定义或改写 |
| 今日最重要的一件事（MIT） | 与北极星相关、本人确认的一个具体行动及完成标准；计划、执行反馈与完成是不同状态 |
| AI 导师讨论结果 | 选定讨论的 AI 观点与总结，保留出处和生成性质，独立展示 |
| 长期记忆 | 可查看证据、纠正、归档和删除的事实/观察；不等于所有聊天原文 |
| 导师私聊 | 一个固定导师下的独立问题及其历史；不自动共享给其他导师 |
| 问题 | 长期保留的讨论主题，有当前背景和历次讨论 |
| 一次讨论 | 对问题发起的一次参考或辩论；停止、恢复、重试不会自动变成无限的新场次 |
| 当前背景 | 带版本和来源的用户情况、计划、实际反馈与 AI 建议，继续讨论时按类型选择 |
| 同步 | iPhone 与本人账号的产品服务空间交换所选内容；与交给模型处理分开控制 |

使用顺序保留为：**直接打开今日模板日记 → 按需确定 MIT → 白天随手记录 → 晚间反馈 → 周报 / 月报 → 调整下一步**。导师和记忆服务于这条日常使用流程。

本轮用户旅程是根据已提出目标编排的**设计场景，不是用户访谈实录**：

- **UJ-1 打开就能写。** 第一次打开也直接进入今日模板的本地页面；已有内容立即显示，账号和同步可以以后处理。只有请求需要账号的智能功能或启用同步时，才出现简短登录/说明弹层；不要求配置服务器。
- **UJ-7 早晨明确今天的一件事。** 今日模板已直接打开；查看当前北极星与阶段目标，生成一个 MIT 草稿，调整并确认后写入对应区块，晚间记录实际进展。
- **UJ-2 路上把想法留下。** 在今日日记底部点麦克风、录音、就地校正转写，原始录音先本地保留；断网也能退出，下次接着整理。
- **UJ-3 晚上完成日记。** 当前日期与区块已带入；本人输入在原页确认保存，AI 改动在底部预览确认，成功后原页出现新内容；不确定是否成功时先查结果。
- **UJ-8 用周期复盘调整行动。** 选择上一周或上月，检查可用日记与缺口，按原模板生成复盘，校正并确认保存；从复盘进入指标复核和新的 MIT，历史记录保留原版本。
- **UJ-4 继续一个问题。** 向主持人反馈进展，查看更新背景，明确邀请导师参考或辩论，最后选择是否保存 AI 结果。

- **UJ-5 修正系统对自己的认识。** 从记忆卡看证据，纠正事实或收紧权限；删除与重新提取的范围由本人选择。
- **UJ-6 Air 不在线时照常记录。** 只展示本机已有内容，待发内容可取消；恢复连接后核对版本、权限和任务状态。

## 4. 功能要求

### 4.1 首次使用与身份（UJ-1）

<a id="fr-01"></a>
**FR-01 打开即可本地记录。** 启动直接打开按日记时区计算的今天；包括首次安装、未登录和服务暂不可用。今日内容已在手机时立即显示；尚未创建则就地准备有效模板的新日记，不先展示欢迎/配对/配置页。文字和录音先在本机保存；没有历史模板时使用明确标识的产品初始模板或先保留自由输入，不冒充已经迁入用户原模板。

<a id="fr-02"></a>
**FR-02 产品服务与按需身份。** App 预置产品服务入口，普通用户不输入地址、配对码、模型名称或 API Key，也不安装 VPN 作为使用前提。请求需要账号的智能能力或启用同步时才登录/创建产品账号；成功后回到原日记/请求位置，不再进入配置向导。未登录可以持续使用本地记录。当前已有用户经可信迁移映射到其既有 owner；其他账号必须建立独立 owner 和文件、记忆、会话、任务、预算、缓存与导出范围，不能默认映射到维护者的私人资料。维护者连接配置放设置深处并限制角色，不是普通账号的流程。

<a id="fr-03"></a>
**FR-03 同步范围放在设置。** 日记可先本地使用；在设置 → 账号与同步中明确开启服务同步、选择日期范围与附件，显示预计空间和可用空间。登录不自动上传全部本地内容，服务同步不自动开启 AI。已同意同步的账号可后台恢复既有范围，默认建议先下载最近 30 天 [A4]；初次下载、暂停或失败都不阻挡今天本机记录。

<a id="fr-04"></a>
**FR-04 智能权限按使用场景说明。** 首次调用具体智能功能时，在原页面用简短说明呈现此次内容范围、用途与实际接收方；已有有效授权不反复弹出。历史提取、新增/修改提取、记忆整理、导师召回的详细开关在隐私设置，不能把四项设置做成启动必经页。账号登录不重新初始化历史，不放宽原授权；新增范围或接收方变化再核对。

### 4.2 日记阅读、搜索与本地文件（UJ-1、UJ-6）

<a id="fr-05"></a>
**FR-05 首页直接是今天正文。** 日记标签默认展示今日 Markdown 与原模板结构，顶部日期切换和目录，底部固定文字/麦克风入口；今日 MIT 在原区块自然展示。没有“进入日记”二次按钮，没有服务配对、模型配置和大块同步状态卡。周/月复盘、北极星、历史与搜索放日记目录，设置在更多。状态仅用“已保存在手机 / 同步中 / 待处理”一行提示，点开才看详情；重要写入失败仍就地明确提示。

<a id="fr-06"></a>
**FR-06 原文阅读与 AI 区分。** 渲染已有 Markdown 标题、列表、表格、链接及本地附件；本人正文与 AI 导师讨论结果有持续标识。AI 结果默认收在专属区域，选择后可看来源与所属场次。不能将“打算做”显示为“已经完成”。

<a id="fr-07"></a>
**FR-07 有范围的搜索。** 首版支持本地已下载日记的文字/日期搜索，联网可显式扩大到 Air 已有日记。显示范围、筛选与下载情况；未命中只说“在本次范围内未找到”，不声称某天没有经历。记录日期和内容里的事件日期分开处理。

<a id="fr-08"></a>
**FR-08 文件与附件可带走。** 我的日记保持 Markdown；录音为常规音频文件，引用关系可随所选日记导出。App 管理的文件可经“文件”入口访问/导出；不承诺直接读写另一个 App 的任意目录。导出不改变后台事实库，`MEMORY.md` 是只读快照。

### 4.3 语音与文字记录（UJ-2）

<a id="fr-09"></a>
**FR-09 页内随手记。** 点击今日页的空白输入位置或底部输入条即可打字，当前日期和区块默认带入，可直接改。输入自动保存在手机；这不等于服务端正式写入。在同页看得到待保存文字及新增位置，点一次“保存这段”确认当前版本，成功后内容出现在原区块、输入条清空，日期和滚动位置保持。无需再去记录页、建日页、通用预览页和成功页。AI 整理是可选动作。

<a id="fr-10"></a>
**FR-10 录音全过程。** 点击录音时才申请麦克风权限；拒绝后可改打字或打开系统设置。录音有时长、暂停、继续、结束和回放；电话/音频会话打断、锁屏、空间不足或 App 异常后明确显示最后一段可用录音。删除录音需单独确认，AI 整理不会自动删除原音频。

<a id="fr-11"></a>
**FR-11 转写的实际位置可见。** 优先验证设备端中文转写。明确显示“在此设备转写”或“使用在线转写”；本机能力不可用时让用户保留录音、改打字或显式选择产品已提供的在线转写。在线转写说明音频发送到产品服务及实际处理方，不能因隐藏主机名称而声称音频仍在手机。断网、模型资源缺失、空转写和失败可恢复，不能承诺所有机型离线可用。

<a id="fr-12"></a>
**FR-12 转写可校正。** 转写与原录音关联，可回放、改字、保留原稿；以校正后的文字请求整理。出现不确定词时给出核对提示而非捏造内容。首版不要求实时字级时间戳；长录音支持分段保存并防止重复段落。

<a id="fr-13"></a>
**FR-13 可选 AI 整理。** 原文可以直接保存；本人选择整理时才提交获准文字。进度与结果在当前日记的底部弹层，先核对原文和整理后内容再确认；不把整理强制插进每次记录。关闭弹层保留原稿，完成后回原日期/区块。

### 4.4 保存、编辑与同步（UJ-3、UJ-6）

<a id="fr-14"></a>
**FR-14 确认放在当前上下文。** 本人新增原文的页内输入区同时呈现文字、目标日期与区块，可以构成精确预览；点“保存这段”即确认该版本，不重复要求第二次同义确认。AI 整理、导师结果与复盘使用同页/弹层差异预览再确认。后端仍校验草稿、本人、目标与内容版本、30 分钟时效、一次性确认及幂等；内部取得草稿与回执不等于用户必须逐个跳页。若确认已过期、授权已失效、服务端实际预览不同于本人所见，或目标/原文/来源改变，需保留原稿并刷新预览重新确认；不能为简化页面而自动确认不可见改动。

<a id="fr-15"></a>
**FR-15 同页反馈保存结果。** 本机落盘后立即显示“已保存在手机”；服务端确认才显示同步/写入已完成。正常成功只更新当前日记与一行状态，不跳成功页、不弹详情清单；模型记忆处理进度放详情中。响应未知时当前页保留文字并查询原操作，不能重复追加。

<a id="fr-16"></a>
**FR-16 待发队列与未知结果。** 离线时保留本地记录、转写和编辑，不排队一个无限期有效的 AI 写入确认。联网后重新获取最新预览，由用户确认。已发保存请求超时则先查同一操作的回执，结果未明时不重新提交。未发送操作可取消；已发送操作的“取消”不得承诺撤销已写入内容。

<a id="fr-17"></a>
**FR-17 人工编辑已有正文 [A3 待确认].** 本人可对已下载日记产生本地修订；同步前对比 Air 当前版本，展示将修改的差异并明确确认。编辑不丢失未知 frontmatter、模板结构或 AI 来源标记。AI 仍只生成受限草稿；不得调用人工编辑通道任意重写文件。首版是否包含此能力由本轮走查决定，未确认前不作为实施授权。

<a id="fr-18"></a>
**FR-18 冲突与恢复。** 手机和 Obsidian/Air 同时修改时保存双方版本；展示逐段差异，可选择保留 Air 版、保留手机修改形成新修订，或手动合并。所有选择再次预览且保留可恢复版本，不静默覆盖。源文件改变后相应记忆依据变旧，先停用旧依据，再按授权重新处理。

### 4.5 固定导师私聊（UJ-4）

<a id="fr-19"></a>
**FR-19 固定导师与独立问题。** 展示温柔回顾者、直率教练、未来的我、王阳明导师；主持人负责问题接话与组织。每位导师有独立问题列表，可新建、续聊、查历史、归档或删除。返回旧问题时显示本问题上下文，不借用另一个导师的私聊。

<a id="fr-20"></a>
**FR-20 连续理解与依据。** 续聊保留相关本人原话与该导师已交付回复，保留人/AI 类型和来源。回答可打开实际使用的记忆或日记出处；原文检索工具尚未在该路径完成验证时明确禁用，不暗示已查遍日记。新 App 私聊自动记忆需接齐撤权与删除抑制，未完成时显示“此入口自动记忆尚未启用”。

<a id="fr-21"></a>
**FR-21 回答进度与失败。** 等待时能看到已接收、排队、导师回答中；展示实际阶段而非虚构百分比。可离开页面后回来查看。把网络、Air 不在线、模型登录/额度、来源失效、结果未明区分成可行动的文案；模型未知结果先核对，不能把所有失败按钮做成重新生成。

<a id="fr-22"></a>
**FR-22 材料显式转交。** 将选定私聊内容交给另一导师/圆桌前，预览实际文字、来源类型和接收者；默认只选本人指定内容，不附带完整历史。来源限制继续继承；接收方不获准的内容不能通过复制摘要绕过。删除/纠正原来源后，转交派生内容同步失效。

### 4.6 持续问题与圆桌（UJ-4）

<a id="fr-23"></a>
**FR-23 问题长期保留。** 在导师入口进入“我的问题”；一个问题具有标题、当前背景、主持对话和历次讨论。普通补充只让主持人接话并更新可追踪背景；明确选择“请导师参考/辩论”才发起全桌。新问题不自动复制旧背景；归档后可恢复，恢复不自动调用模型。问题背景与完整档案不自动成为跨问题长期记忆，保存讨论也不触发该升级。

<a id="fr-24"></a>
**FR-24 背景与条件有版本。** 当前后端背景是有界的来源摘录，达到范围上限时应提示“背景待整理”，由本人明确发起整理；不得假称自动压缩已完成。展示更新时间、覆盖范围、本人原话、计划、实际反馈和 AI 建议。用户可纠正事实、补充已执行结果、查看旧版本。重新分析可选择不沿用旧 AI 判断，保留本人事实与历史档案。背景摘录待更新或来源失效时显著提示，不能把旧摘录显示为最新理解。

<a id="fr-25"></a>
**FR-25 分享范围可核验。** App 新问题默认“仅本问题内容”。使用个人记忆或日记时，用户先选材料/获准范围，查看实际使用说明与全部接收导师，再确认。本轮建议沿用“主持人＋四位固定导师”为问题成员，2–4 位是本次发言者，少选发言者不自动缩小分享范围。个人来源模式在后端尚未通过逐次权限校验、撤权生效和缓存失效验收前禁用；iOS 连接不替飞书 `group_only` 问题扩大权限。

<a id="fr-26"></a>
**FR-26 参考、辩论与控制。** 选择 2–4 位导师，先独立观点，再比较；参考模式即使发现冲突也只呈现比较，须本人选择升级后才进入辩论；已选择辩论模式时，也只有有依据的实际冲突才进入交锋，互补意见可直接综合。可选最多 1 或 2 轮，默认 2 轮为既有建议。展示作者、阶段与顺序；支持补充、先总结、停止。补充使陈旧生成失效；停止确认后不展示迟到结果，不承诺退回已发生的模型消耗。

<a id="fr-27"></a>
**FR-27 结果、场次与恢复。** 综合保留条件、分歧、少数意见、依据及下一步。参考升级辩论沿用同次预算；明确“重新讨论”才创建新场次。Air 重启、休眠或结果未明时展示真实暂停原因；只在后台证明可安全继续时提供继续按钮，未知结果提供核对/保留已完成部分，不自动接着跑。

<a id="fr-28"></a>
**FR-28 单独保存 AI 结果。** 选定同一场次的发言/综合，到 App 私人保存页改日期或改草稿并重新预览，确认后写入“AI 导师讨论结果”专属区块。保留 AI 类型、问题、场次、来源和保存回执；默认不进入本人事实自动提取。用户后来明确说“我做了……”才作为单独本人反馈处理；勾选采纳计划不等于已执行。

### 4.7 长期记忆与来源管理（UJ-5）

<a id="fr-29"></a>
**FR-29 记忆概览与证据。** 展示共享事实、导师私有观察、待复核项及阶段性变化。记忆卡包含原文、类型、归属、时间、有效状态、处理权限及证据；进入原文时保留实际片段位置。无来源、已失效和未下载分别说明；手机离线副本标注最后同步时间，不能据此启动云端召回。

<a id="fr-30"></a>
**FR-30 纠正、复核、归档。** 用户可纠正内容、确认仍有效、归档和恢复，并查看变更历史。人工纠正优先于后台候选；观察不自动升级为事实。自动提取的推断保留在本人账号的记忆空间，默认不供后续模型调用，由本人单独决定是否允许 AI 使用；这不表示内容仅存在手机。收紧来源/记忆权限后，依赖的摘要、缓存、待发请求及后续召回一并受限；离线修改先标记待同步，不能声称已阻止 Air 使用。

<a id="fr-31"></a>
**FR-31 可解释地遗忘。** 删除前说明选定记忆、依赖观察/摘要、来源是否继续参与提取以及原日记是否保留。默认删除选定记忆并阻止同一来源版本自动重建；允许选择进一步撤回对应来源处理范围。同步删除覆盖 App 缓存、来源索引、待处理派生数据；不会承诺擦除用户导出、系统备份或已离线设备上的副本。首版 App 不提供删除服务端日记原件的按钮；移除已同步手机副本属于清缓存。当前维护者在既有文件工具删除原日记时，下一次同步标记删除并使来源/派生记忆失效；普通账号不依赖登录维护主机来管理资料，其自助删除正式原件/账号空间须有单独设计与验收后开放，不能把维护者工具当作普通用户功能；本机未同步修订保留为冲突，不自动复活原件。完整原件回收站另行设计。

<a id="fr-32"></a>
**FR-32 处理覆盖与控制。** 分别展示已发现、成功、排除、待处理和失败来源；不把记忆数量当作完成率。有暂停、继续、查看失败和受控重试，显示日常额度及已冻结历史批次的实际状态。App 首次登录不能重开初始化例外；暂停提取不等于停止现有记忆召回或当前聊天。

### 4.8 设置、连接与数据退出（UJ-6）

<a id="fr-33"></a>
**FR-33 权限随处可达。** 记忆相关页面保留可见权限摘要及“管理/暂停/撤回”入口；详情明确四用途、接收方、来源范围、导师集合、自动聊天捕获和音频处理位置。来源 `private: true` 与 `none/local/cloud` 规则保持；账号同步许可不自动赋予模型处理许可；旧 local 标记在产品中解释为不供后续 AI 使用，不等于仅存在手机。

<a id="fr-34"></a>
**FR-34 账号与服务状态分层。** 普通设置只显示账号、同步、智能服务可用性、已登录设备和最近成功同步；故障文案是“暂时连不上服务，记录已保存在手机”，不要求用户去检查 Air、Tailscale 或模型登录。维护者高级页才显示主机/连接/模型诊断。设备凭据安全保存，模型凭据不下发；换账号时隔离旧文件、记忆、待发任务、确认及缓存，不自动上传上一账号或游客草稿。撤销设备后后端拒绝访问；离线副本不能远程立即抹除。

<a id="fr-35"></a>
**FR-35 空间、导出与恢复。** 查看日记、录音、已下载附件与未同步原稿占用；清缓存只移除已确认可重新取得的副本。导出可选 Markdown/音频、只读记忆快照、结构化记忆备份或所选讨论。恢复先校验包与范围、预览冲突；讨论恢复为只读档案，来源授权不继承为新的许可。恢复不自动启动 AI 或复活已删除记忆，需保留删除抑制状态。

<a id="fr-36"></a>
**FR-36 后台能力与渠道兼容。** App 后台获取实际可用功能，不把“能力协商”“provider”作为用户操作。功能暂不可用时在当前功能内解释并保留本地路径。已有用户的可信身份映射可复用其旧资料；其他账号不共享该 owner。旧飞书和 group_only 规则继续独立生效。

### 4.9 原模板与每日日记（UJ-7）

<a id="fr-37"></a>
**FR-37 原模板完整保留。** 新用户先用明确标识的产品日/周/月初始模板，不要求迁移外部文件；已有日记用户接入本人现有日、周、月模板，展示来源、版本和区块预览。保留 frontmatter、自定义标题、表格、任务状态、链接、占位符与既有字段，不把用户模板换成通用聊天卡。Morning、MIT、Today's Tasks、Workout、Evening、Self Reflection、Daily Learning、Notes 是当前架构可见锚点，实际以用户模板为准；未取得的完整模板不得用演示模板冒充。模板中的脚本、插件字段或外部数据只做能力识别；不支持时逐项提示、保留占位内容，不执行任意脚本，不擅自删字段。天气、睡眠、任务和专注时长等原有字段保留；原数据源及填充规则逐项迁移验收，未接入时允许手填，不填虚构值。

<a id="fr-38"></a>
**FR-38 今日模板就地准备。** 打开今天时直接显示已有日记；没有文件时根据已有效配置的模板准备可编辑的本地页面，首次输入或本人选择保留空白日记后可靠落盘，不反复要求选择模板、确认日期和点击创建。模板准备本身不调用模型，也不自动上传空白文件。默认规则在日记偏好可改；补建历史日期、更换模板和处理冲突才显示专用预览。服务端新建仍走明确保存意图或原已批准的自动创建策略，已有文件不覆盖。离线有有效模板时照常写；恢复后同日文件碰撞保留两边输入，核对实际新增内容再确认。日期固定为用户日记时区，跨午夜时保留正在编辑的日期并提示切到新一天，不默默移走原稿。

<a id="fr-39"></a>
**FR-39 保留整天的使用方式。** 每日页按原模板显示晨间计划、MIT、任务/习惯、已有健康/专注字段、晚间回顾、反思、学习与自由记录；每个记录入口带上目标日期和原区块。字段未填写、未同步、数据源未配置、真实数值为 0 分别展示；不能拿缺失当作 0。语音是这些区块的输入方式之一。MIT 与任务的实际反馈可进入当天记录、周报与月报，勾选计划不自动视为已完成。

### 4.10 周报与月报（UJ-8）

<a id="fr-40"></a>
**FR-40 从日记生成周报。** 周报入口可选当前周、上一周及任意历史周；默认完整上一 ISO 周（周一至周日），原配置若不同则显式沿用其口径。生成前显示确切起止日期、日记时区、已发现/可用/缺失/排除的来源与模板版本。当前周标为“进行中”。按原周模板整理目标进展、MIT 执行、学习、关系、状态及下一步等已有栏目，事实附可回看的来源；选定范围不等于获准把完整文件出云，模型只处理当前请求获准的受限片段。证据不足时可补记录、缩小范围或明确生成部分复盘；不能臆造缺失天数的活动或指标值。

<a id="fr-41"></a>
**FR-41 从周报与日记生成月报。** 可选择上月、当月或历史月，预览精确自然月范围，按原月模板汇总主题、北极星/阶段进展、资源分配及下一阶段重点。已确认周报用于组织线索，结论能追溯原日记；跨月周报只取目标月内有日期依据的内容，同一经历/任务/数值不因同时出现在日记和周报重复计数。周报缺失时可用该月获准日记，明确降级依据；无足够日期证据不把跨月汇总硬拆为精确数值。月报不自动修改北极星定义或目标。

<a id="fr-42"></a>
**FR-42 复盘生成、校正、保存与回看。** 周/月报均经过范围确认、任务进度、可编辑草稿、目标类型与差异预览、本人确认、保存回执，再进入日/周/月列表和 Markdown 导出。区分 AI 分析、引述事实、本人补充和计划，不将生成报告重新提取为独立的新事实证据。已存在报告时先打开；重新生成保留旧内容及版本，确认后按受控新版复盘区块追加，不静默重写本人修改。生成失败与保存结果未明分开处理；离线保存草稿，恢复后重验来源/模板/目标版本，过期预览重新确认。周、月报不能借每日追加接口写入 daily 目录；需要独立的受控目标与幂等契约。原来源改变或撤权时，相应分析和依赖 MIT 标记待更新，保留可读历史但不把旧依据用于新推理。

### 4.11 北极星、今日 MIT 与日常自动化（UJ-7、UJ-8）

<a id="fr-43"></a>
**FR-43 沿用本人北极星指标。** 导入并展示现有北极星定义、指标口径/单位、目标周期、已确认目标、当前阶段和来源版本；若原配置有多项指标，不擅自压成一个。当前数值只有在有来源时显示，并注明统计截止时间。不存在配置或数值缺失时明确提示，由本人录入/纠正；AI 不编造人生目标、指标值或自动改目标。本人修改先预览并确认，保存为新版本，历史日报、周/月报和 MIT 保留当时引用版本；同步指标配置不自动授权发给模型。

<a id="fr-44"></a>
**FR-44 每日最重要的一件事。** 对选定日期，使用本人确认的北极星版本、阶段重点、当期复盘和相关实际反馈，在明确展示使用范围后生成**一个**推荐 MIT 草稿；说明为何推动该指标、具体行动、可验证完成标准及建议投入。本人可修改、手动填写或重新生成；确认才写入当天模板的 MIT 区块。没有指标或依据时先补配置/改用手动计划，不输出假称基于北极星的建议。一天只保留一个当前确认的 MIT，重新打开不重抽；更换通过追加变更记录保留旧计划，不能覆盖原文。未完成不自动顺延、已推荐不等于已采纳、已采纳不等于已完成；晚间可记录完成/部分/未做、实际结果与原因，明确确认后追加到原模板的反馈位置。周月复盘使用这些真实反馈，形成“指标 → 行动 → 反馈 → 复盘 → 下一步”循环。目标、来源、日期变化后旧草稿须重新核对，不沿用旧确认。

<a id="fr-45"></a>
**FR-45 原日常自动化可迁移、可手动运行。** 新账号可使用产品提供的日常任务设置，尚未开启就显示未开启；已有用户沿用并迁入原任务。App 显示从后台实际读取的新建每日日记、周报、月报及已有字段填充任务：触发时间、时区、启停、上次结果、下一次计划与待确认草稿。MIT 支持手动请求，也可由本人在 App 显式设置日常生成。配置持续任务时确认资料范围、模型接收方与用途；每次执行重新校验，范围或接收方变化时先停用，重新确认后继续；具体时间继承原设置，读取不到时标为“尚未迁入”，不拿 pack 示例时间当实际运行。已有任务按稳定身份接管，避免旧自动化与新 App 重复生成。Air 承接定时运行；模板建日只在已有或新明确批准的创建策略内执行，已存在即跳过；AI 周/月报及 MIT 默认生成待确认草稿，不自动写入为本人已确认内容。断线或休眠后的漏跑先列出周期与来源供本人选择，不补建无限历史、不重复触发；模型/来源/预算失败保留原因和同一任务状态。修改时间/停用须展示变更与 Air 确认状态。本轮只设计这些入口，不创建或修改真实定时任务。

## 5. 数据与权限的可见规则

| 用户操作/状态 | 手机上保留什么 | 产品服务做什么 | 模型提供方是否接收 |
| --- | --- | --- | --- |
| 离线打字/录音 | 原稿与录音 | 未收到 | 否 |
| 明确启用账号同步 | 所选文件副本与待发版本 | 接收并保存账号独立的选定文件；属于远端数据传输 | 不因此发送给模型；不能称为只在本人设备 |
| 本机转写 | 录音、转写 | 不必接收音频 | 本机转写模式不发送音频 |
| 选择在线转写 | 本地原稿 | 接收获准音频，由配置的转写服务处理 | 使用第三方时明确实际接收方，不能静默更换 |
| AI 整理/导师对话 | 草稿/回复及状态 | 校验身份、来源和用量 | 发送当前明确提交内容及必要获准上下文 |
| 周/月报与 MIT 生成 | 本地草稿、选定指标与来源版本 | 校验当前请求的资料范围并生成可确认结果 | 只发送本次生成或已配置持续任务明确获准的指标与受限证据；同步和四用途记忆授权不自动授予周/月报与 MIT 生成权限 |
| 按模板建日记 | 日期、模板版本、本机新文件 | 检查是否已有文件，受控实例化 | 模板建空白日记无需调用模型 |
| 自动日记记忆 | 缓存结果与进度 | 提取、来源校验、存储、整理 | 仅在对应用途授权内发送受限内容 |
| 收紧权限/删除，尚离线 | 待同步标记，本机停止对应使用 | 尚未收到 | 明确提示 Air 仍可能按旧授权处理 |
| Air 已确认撤权/删除 | 同步更新副本 | 拦截后续调用与派生使用 | 不能撤回已经发出的请求 |

日记“私密/仅本地”约束 AI 使用；本人选择把该文件同步到产品服务是另一项远端同步授权。若用户要求“只留此手机”，则该记录不上传 Air，不形成 Air 记忆。导出、系统分享与备份单独说明接收范围。

## 6. 故障时用户应看到什么

| 情况 | 用户文案与可执行操作 |
| --- | --- |
| 普通用户无法连服务 | 原页提示稍后重试，文字/录音继续留在本机；诊断主机和网络入口由维护者处理 |
| 无网络 / Air 不可达 | “已保存在此 iPhone，尚未同步”；继续写，查看本地内容，取消未发送任务 |
| 初次同步未结束 | 展示已下载数量与范围；暂停/继续，未下载内容明确标注 |
| 麦克风拒绝 / 转写不支持 | 改打字、保留录音、打开设置或选择已配置的 Air 转写 |
| 保存请求超时 | “正在核对保存结果”；查回执，结果未明时不重复写入 |
| 草稿过期 / 原文变化 | 保留草稿；刷新差异后重新确认 |
| 两端编辑冲突 | 双方版本可读；合并、选用某版形成新修订或暂不处理 |
| 模型登录/额度问题 | 本地记录继续；说明需由产品服务处理，不让普通用户自行配置模型 |
| 讨论停止 / Air 重启 | 保留已完成发言；可验证安全时再继续，未知结果先核对 |
| 来源被改动 / 撤回 | 派生认识标为待更新或不可用；不展示旧依据为当前事实 |
| 设备失效 / 换账号 | 暂停远端访问；隔离旧副本与队列，先保护未同步原稿，再登录；不上传旧账号内容 |
| 模板/北极星配置缺失 | 显示未迁入或不支持的具体项；先存原稿、查看模板或本人补配置，不用假模板/假指标代替 |
| 周月资料不足 / 来源过期 | 显示缺口或受影响段落；补资料、明确生成部分草稿或重新核对，不声称完整复盘 |
| 既有复盘或今日 MIT 已存在 | 先回看已确认内容；本人明确更换才生成新预览，保留旧记录 |
| 日常任务漏跑 | 列出实际漏跑周期、上次状态；用户选择补跑，结果未明先查询，避免两套调度重复运行 |
| 本机空间不足 | 停止新增大文件、保护已保存原稿；清理可重下缓存或导出 |

## 7. 首版质量与验收

以下均为**发布目标，尚未实测**。性能以明确的测试机型、iOS 版本和合成数据量报告，不把模型质量评测成绩当作网络可用率。

- **可靠记录：** 指定参考机型上，文字输入停止后 1 秒内落本地持久存储，首次日记页面在 2 秒内显示已有本地内容；杀进程/断网恢复只允许丢失尚未达到保存完成状态的输入。录音分段与恢复边界须真机验证。
- **原文不丢失：** 断网、重复点击、客户端重启、Air 重启、文件外部修改、满磁盘测试中，不覆盖未合并版本、不重复追加、不删除未同步原稿。
- **权限不扩大：** 新登录/换账号、服务切模型、增导师、离线旧缓存、撤权中在途请求、跨私聊转交均有失败路径；源约束不能被 AI 摘要或来源类型转换绕过。
- **持续对话：** 四导师同题跨三次续聊保留相关本人事实；换问题/换导师不串入私有历史。圆桌保留反对意见，互补建议不被强行编成冲突。
- **结果可信：** AI 结果保存后在阅读、检索、导出、记忆提取中保持 AI 类型；计划/建议被记成已发生事实的受控验收错误为 0。
- **移动端可用：** VoiceOver、较大字体、浅/深色、360pt 等效窄屏、键盘遮挡、来电打断、锁屏和重新启动均实测。主要触控目标至少 44pt；重要状态不能只用颜色表示。
- **日常操作简洁：** 冷启动直接进入今天，启动前置配置数为 0；新增原文从当前页一次点击进入输入、一次明确保存，成功不换页；录音从当前页一键开始（首次系统权限例外），结束后在同页校正保存；无自动调用 AI。
- **产品统一服务：** 普通账号无服务器/Key/VPN 设置依赖；账号 A 不能读取、检索、续聊、恢复或导出账号 B 的资料，包含缓存、后台任务、录音和推送。验证前不能给外部账号默认绑定维护者 owner。
- **原功能迁移不缺项：** 用户现有日/周/月模板逐区块比对；使用原规则完成新建日报、周报、月报及北极星到 MIT，不能仅证明文件能读。天气、睡眠、待办与专注等实际原字段/任务按清单核对，缺项留可见状态。
- **周期与行动准确：** 覆盖跨月周、年末 ISO 周、时区午夜、当前未结束周期、缺日记和重复证据；当前 MIT 唯一，未做不计完成，报告不重复提取为新事实，来源/目标变化使待确认结果失效。
- **自动化兼容：** 验证原任务接管、已有文件跳过、重复请求、Air 休眠后漏跑与恢复；未确认的 AI 复盘和 MIT 不自动写入。
- **完整记忆闭环：** 至少真机验收一次“App 确认本人日记 → 按既有授权增量提取 → 显示有效来源 → 导师使用正确记忆回答”。存量记忆展示不能替代此闭环。独立私聊自动捕获若未完成可暂不启用，并显著说明；日记来源增量记忆属于首版必需。
- **真实链路：** 在合成库上分别完成产品网络/蜂窝访问、登录与设备撤销、30 分钟中文录音、Air 不在线及重新上线、App 中确认写入、来源纠正与记忆失效。暂以 30 分钟为 [A5] 验收样本，并非承诺时长上限。

首轮两周个人试用关注：一次记录到确认保存是否顺畅，跨日续聊是否减少重复背景，能否找到并修正错误记忆。记录任务成功率和失败原因，目标由试用基线校准；不以更多模型调用、更多记忆条数、更长讨论或更高共识率作为成功指标。

## 9. 本轮低保真范围

一个离线 HTML，所有核心页面和异常状态默认平铺可见；按今日页、页内文字/语音及保存、日记目录与原模板、MIT 与复盘、导师、记忆、按需账号与设置顺序排列；维护者连接放最后。每个页面/同页状态/底部弹层有稳定 ID、来源 FR、入口、状态、用户操作及跳转目标；按钮只在原型内跳转，全部示例虚构。

低保真重点检查：原模板及区块是否保留；周/月报是否能从原始依据生成并确认保存；是否能根据北极星形成一个每日 MIT 并收集实际反馈；日记能否先本地保存；录音失败是否有去处；确认写入是否独立；私聊与圆桌分享是否明确；背景、事实和 AI 是否能辨认；遗忘、撤权和未知结果是否能理解。
