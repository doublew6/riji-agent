## 1. 范围与使用方式

首版包含原目录和日/周/月模板、Markdown 正文编辑、日期与搜索、北极星与每日最重要的一件事（MIT）、周记/月记及原有任务、长期记忆、固定导师私聊、圆桌、离线与冲突恢复、本人设备连接、资料使用控制和导出恢复。

语音是条件项：先验证系统键盘听写，适用且无按量识别费用才纳入。独立录音/转写没有合适方案时暂缓，保留已有代码和录音，不阻挡文字版交付。AI 整理或对话的费用与语音识别费用分别处理。

本版不做公众注册、多用户商业服务、收费、商业上架、iPad/Mac 新客户端、独立的 Air 日记同步、任意 Obsidian 插件执行、强制长录音或付费语音服务。

底部导航依次为 **日记、导师、记忆、设置**，四项并列。日记默认今天；目录承载历史、搜索、周记/月记、北极星与模板，不再附加单独的设置栏。服务器和模型配置放设置内层。

已确认的使用路径：

- **UJ-1/3 记录今天：** 打开原模板，点正文输入、修改或勾选，自动保存，没有独立输入框、区块选择或逐段保存。
- **UJ-7 计划与反馈：** 查看本人北极星，确定今天一个 MIT，记录真实执行情况。
- **UJ-8 周记/月记：** 打开原文件，或按原模板生成、校正和保存，沿用 Air 既有任务。
- **UJ-4 请教：** 点首页导师人物进入固定私聊；群消息与输入框直接位于导师首页下方，在当前页切换群并继续聊，不跳聊天页。需要多人时选择导师建群，创建后在首页显示新群；旧圆桌继续按原身份保留。
- **UJ-5 纠正记忆：** 查看记忆与原文依据，纠正、复核、归档或删除。
- **UJ-6 离线：** 继续编辑已下载文件；AI 状态单独显示。冲突保留双方，未知写入结果先核对。
- **UJ-2 语音条件路径：** 免费听写可用时，文字进入当前正文位置，能校正和保存。

## 2. 文件、服务与术语

**日记文件**是本人原目录中的 Markdown，Obsidian 和 Riji 都是这套文件的编辑器。App 通过本人授予的目录权限读写设备端文件，iCloud 传播变化。沙盒可保留草稿、恢复版本和缓存，不另建一套需要与 Air 对账的权威日记。

**周记/月记**沿用原 `weekly.md` / `monthly.md` 的结构与既有文件名规则。**MIT**是本人确认的计划，采纳、实际反馈、完成是不同状态。**AI 讨论结果**保留 AI 性质和讨论来源，不自动成为本人经历。

**长期记忆**由 Air 既有服务管理，手机展示副本和状态；共享事实与各导师的私有观察、聊天历史分别处理。**圆桌**以持续聊天呈现，后台保留讨论来源与场次，本人无需先管理问题或话题。

Air 负责模型调用、记忆处理、导师与原有自动化，实际模型可按配置在云端推理。Mem0/SQLite 和凭据留在 Air 原运行位置，不移入 iCloud。文件同步、Air 读取、模型处理和记忆生效是不同状态，不能合称“全部同步完成”。

## 3. 功能要求

沿用 FR-01 至 FR-45 的稳定编号，以对应历史原型和验收；编号不代表旧公众产品方案继续有效。

### 本人入口与权限

<a id="fr-01"></a>
**FR-01 打开即今天。** 已授权目录时直接进入今日正文；首次未选目录则就地提供系统文件夹选择，不先配置 AI。取消保留原状态，不假称已取得原模板。

<a id="fr-02"></a>
**FR-02 本人设备连接。** App 使用预设的服务入口访问本人 Air，日常使用不要求本人打开 Tailscale、填写服务器地址或处理配对码。本人身份与设备授权由产品接入流程承接，个人安装时可由开发侧完成受控配置；不把模型密钥或管理凭据打包进 App。服务失败不阻止本地记录；本版没有公众注册或账号切换。2026-09-17 用户再次明确此体验要求：当前开发版的 Tailscale 私网与手动配对仅是已实现接入方式，尚不满足目标体验；正式外网入口和无手动配置的首次授权仍待单独实施、验证。

<a id="fr-03"></a>
**FR-03 沿用原身份。** 设备接入沿用本人已有记忆身份；失效设备停止服务访问和旧队列发送。新设备不重新初始化记忆、不合并未核验的历史、不混淆导师身份。

<a id="fr-04"></a>
**FR-04 资料使用可控。** 沿用历史提取、新增/修改提取、记忆整理、导师召回四用途及来源约束；目录访问、iCloud 同步、记忆处理和模型使用分别说明。目录授权和交互确认不扩大出云范围，详情放设置，日常记录不反复弹说明。

### 日记、原目录与日期

<a id="fr-05"></a>
**FR-05 今日正文与双向切日。** 手指从左向右滑动打开前一个日历日，从右向左滑动打开后一个日历日；按相邻日历标签切换，不跳到最近有文件的日期，也不以今天为上限。缺失或未来日期只展示原模板预览，未编辑或显式保留前不创建文件。切换前可靠保留编辑；保存失败或冲突未处理时留在原文并提供恢复入口。上下滑只滚动正文，选字、光标拖动、输入法候选、编辑状态和表格横向操作不误触日期切换，短距离及明显斜向拖动不切日。日期运算保留跨年、闰日及本地跳日标签，拒绝越过 0001–9999 年范围并留在原日。保留日期选择器及“回到今天”。

<a id="fr-06"></a>
**FR-06 Markdown 排版。** 默认排版标题、任务、列表、引用、原模板表格和常见行内格式，点击正文就地编辑。2026-09-18 用户明确表格交互：点单元格直接输入，编辑时仍保持网格；回车在当前行下方新增一行并继续输入，表头回车在分隔行后插入首个数据行；表格底部、右侧的加号分别追加行、列。新增结构可撤销，保存后仍是同一份 Markdown，保留未修改的内容、对齐与换行。可打开支持的库内链接与本地附件；缺失、未下载或不支持类型有提示。保留未知语法、属性、引用及未编辑部分，不因渲染改写原文、不执行未知脚本或越过目录授权。

<a id="fr-07"></a>
**FR-07 历史与搜索。** 目录、日期和已下载文件搜索可打开原文件并返回原位置，历史日记可编辑。搜索说明范围，无结果或未下载不等于没有该记录。

<a id="fr-08"></a>
**FR-08 原目录。** 按原文件夹树展开，保留名称、层级、位置和附件关系。授权失效可重新选择，取消不清除原连接；未下载文件显示状态与重试，不创建空文件覆盖。

<a id="fr-09"></a>
**FR-09 正文直接记录。** 连续正文支持输入、替换、删除、勾选、撤销、中文组合输入和收起键盘；自动保存并保留日期、光标、滚动位置。没有底部独立输入框、区块选择或“保存这段”。失败保留最新编辑，受保护来源标记不能静默改变性质。

### 语音与可选整理

<a id="fr-10"></a>
**FR-10 录音条件项。** 先验收键盘听写；独立录音纳入后才要求按需权限、暂停/结束/回放及中断恢复。未验证功能不作为正常可用入口交付，不删除旧录音。

<a id="fr-11"></a>
**FR-11 免费且适用。** 验证本人手机中文识别、处理位置与适用条件。不支持则打字，不静默接入收费 API 或上传音频；选择 Air 识别需明确传输范围并验证资源影响。

<a id="fr-12"></a>
**FR-12 校正与恢复。** 听写文字在正文中直接改字；独立转写若纳入，保留原音频、版本及对应关系，防止中断或重复结果重复插入。键盘听写不承诺保留原音频。

<a id="fr-13"></a>
**FR-13 AI 整理可选。** 主动选择后才使用获准内容，先看原文与建议差异再采用。关闭或失败保留原稿，整理不是每次打字的必经步骤。

### 保存、离线与冲突

<a id="fr-14"></a>
**FR-14 人工与 AI 写入分开。** 人工正文编辑自动保存；AI 整理、独立转写插入、导师结果、手动生成的周记/月记与 MIT 按对应预览确认写入。确认绑定本人、实际内容、目标、来源版本和一次性操作；AI/旧飞书保留现有 30 分钟确认时效、原子写入及幂等，不能借人工编辑入口任意重写文件。

<a id="fr-15"></a>
**FR-15 保存反馈。** 2026-09-18 用户确认移除底部常驻的“已保存在此设备”框及同步说明，正常阅读和自动保存不占用底部正文空间，也不跳成功页。保存状态保留无障碍读出；保存失败、冲突和未完成恢复仍就地提供提示及操作。iCloud 同步边界说明保留在设置，本机保存不代表其他设备已收到。响应未知先查同一操作，重试不重复写入。

<a id="fr-16"></a>
**FR-16 离线与待发内容。** 已下载日记可离线写，聊天草稿可保留和取消。取消未发内容不假称撤回已处理请求；联网重验来源和权限，不沿用无限期有效的 AI 写入确认。

<a id="fr-17"></a>
**FR-17 修订与恢复。** 保留原文、编辑和恢复凭据，覆盖切日、页面离开、后台、异常退出及旧草稿恢复。恢复记录异常时可只读查看/导出完好正文，明确未恢复范围，核对前不覆盖该文件。

<a id="fr-18"></a>
**FR-18 iCloud 文件冲突。** 2026-09-18 用户补充：在手机 Obsidian 或电脑修改同一份日记后，Riji 应自动读取到达本机的最新文件，不能拿旧正文继续编辑后才要求处理冲突。离开 App 时保留并保存当前输入，回来立即检查；前台持续检查晚到的文件变化。没有本机差异时自动刷新，文件未变化时不打断输入、光标或撤销。双方都修改时先保留可用版本，再明确提供“使用文件最新版本”“保留本机编辑”或手动合并，稍后处理保留双方。写入前重验，不单按修改时间静默舍弃一方；实际的 iCloud 多版本冲突须与正文已更新区分，不承诺 iCloud 自动语义合并、即时传播或找回未保存的外部版本。

2026-09-19 补充：系统标记冲突不能阻止打开可读取的日记。正文暂时只读，提供“查看并处理版本”；展示当前文件、系统保留的其他版本及已有本机草稿，可查看完整内容、导出、选择版本或手动合并。尚未下载的版本单独说明并可重试，不能让当前正文也无法阅读。处理前先在本机持久备份所有已审阅版本及拟保存结果，再核对文件、目录身份和版本集合；有新变化时保留合并文字并要求重新核对。只能处理本次已审阅版本，不批量清除其他版本；原本机草稿和不确定事务继续独立保留，不能在系统冲突解除后自动覆盖所选结果。处理失败或中断必须提供可恢复入口，不能只留下“有冲突”的提示。

同日交互修正：版本处理默认只展示差异，按章节定位并折叠相同正文；用可读 Markdown 呈现双方片段，表格行变化附带表头。支持逐处保留、采用另一版或编辑该片段，结果作为合并稿持久保留；切换对比版本不能重置已选内容。最后确认也优先展示相对原文件的实际变化，完整原文、导出和整篇编辑作为辅助入口。差异计算在设备本地完成，不将日记发给 AI；替换仅作用于核对时绑定的精确字节区间，不重排或重写其他内容。原有备份、过期核验和显式整份确认边界不变。

同日同步语义修正：普通人工编辑仍自动保存至授权的 iCloud 文件，不把日常同步设计成逐项审批。系统保留的冲突副本必须如此命名，不能称为“云端最新版”或用其内容推断同步失败。显著提供“整份保留当前日记”，差异选择是可选的精细处理。系统冲突已消失时，未修改的旧对照经备份后自动结束；已确认结果与当前文件精确相同、系统版本已处理且备份可核验时，只自动补齐本机完成记录，不重放文件写入。尚未确认的手动合并、内容不同的未完成确认、新冲突、独立正文草稿及损坏恢复证据继续保留，不能仅凭时间或字数自动覆盖。未编辑的旧对照再次打开时读取最新可用文件与版本集合。

### 导师与圆桌

<a id="fr-19"></a>
**FR-19 点导师直接聊天。** 温柔回顾者、直率教练、未来的我、王阳明各有持续私聊，点击即历史和输入区，无问题列表或话题创建。聊天、草稿、待回复状态及私有观察按导师隔离。

<a id="fr-20"></a>
**FR-20 连续理解与依据。** 续聊保留本人原话和已交付回复，能看实际使用的记忆与来源，不假称查遍日记。App/飞书历史衔接在接入前核验，不以共享记忆冒充已导入全部聊天。

<a id="fr-21"></a>
**FR-21 回答状态。** 展示真实等待、回复和失败，离开后可回看；超时查原请求，不重复生成或将迟到回复显示在另一导师页。

<a id="fr-22"></a>
**FR-22 显式转交。** 转交私聊时核对选定文字、来源性质及实际接收者，默认不带完整历史。纠正或撤权影响派生内容，摘要不能绕过来源限制。

<a id="fr-23"></a>
**FR-23 导师私聊与持续群聊。** 2026-10-17 用户明确确认“在导师首页直接聊天，不跳页面”，按[专项 PRD v0.3.3](product/PRD-mentor-dialogue-interaction.md)覆盖此前“首页群列表 → 群聊天页”的解释：上方保留北极星与四位导师人物，点击人物仍进入各自固定私聊；下方直接显示当前群的消息与输入框，通过群切换控件原位切换，同时只显示一个群。键盘弹出或大字号时收紧人物区，优先保证群切换、消息及输入可操作。选择二至四位导师创建后在首页显示新群，群名默认成员组合、以后可改；专题与长期共用一种群，同成员可有多个独立群。私聊与群分别保留历史、草稿、阅读位置及真实回复状态，迟到回复和保存预览仍绑定原群。旧主持人圆桌也在首页显示，保留原身份、成员和接收范围，不合并记录。设计已确认，本次已实现并通过本轮本机回归，待用户体验确认；以往测试不代替本轮验收。

<a id="fr-24"></a>
**FR-24 背景可纠正。** 在对话中补充背景，区分本人事实、计划、实际反馈与 AI 建议；需要时可看覆盖范围、依据和版本。过期背景注明待更新，不假称无限记忆或已自动整理。

<a id="fr-25"></a>
**FR-25 材料与成员。** 新群的实际接收范围就是所选导师，没有隐藏主持人。普通消息每位成员至多回应一次，@ 只指定回应者，群消息仍对全部成员可见；不自动带入私聊、其他群、日记或北极星。主动转交仍核对实际材料和目标；私人日记/记忆用途沿用原权限。旧圆桌继续显示其原有“主持人＋四位固定导师”范围，不把发言人选择冒充权限缩小。首版不提供中途加减成员。

<a id="fr-26"></a>
**FR-26 参考与辩论。** 按选定模式、导师和有限轮次进行；参考不自动升级，真实分歧才交锋。支持补充、先总结与停止；停止后不继续投递迟到结果，不承诺退还已有消耗。

<a id="fr-27"></a>
**FR-27 结果与恢复。** 保留条件、不同意见、来源和下一步。断线或 Air 重启先查原讨论状态，部分与完整结果分开；证实可继续才恢复，重试不无限新建场次。

<a id="fr-28"></a>
**FR-28 保存 AI 结果。** 核对选定结果的日期、文本与原文版本后写入独立 AI 区域，保留性质、来源和回执，默认不提取为本人事实。实际执行后另记反馈，采纳不等于完成。

### 记忆、设置与资料管理

<a id="fr-29"></a>
**FR-29 记忆可见。** 从记忆页看共享事实、导师观察、待复核项及依据，可打开对应日记。无数据、未下载、来源变化和过期副本有明确状态，不把旧依据继续当当前事实。

<a id="fr-30"></a>
**FR-30 纠正与复核。** 可纠正、复核、归档和恢复；本人纠正优先于自动提取，保留历史。服务确认后才显示生效，归档不等于删除或继续召回。推断观察遵守既有仅本地使用限制，不自动升级为共享事实或供后续模型使用。

<a id="fr-31"></a>
**FR-31 删除范围。** 删除记忆保留原日记，阻止同一来源版本自动重建并使依赖项失效；说明删除对象。已导出的副本和系统备份不假称同步擦除。

<a id="fr-32"></a>
**FR-32 处理进度。** 展示真实进度、缺口和失败，支持暂停后续提取、继续和有界重试；已有记忆召回仍遵守权限。存量展示不能代替手机新日记到新记忆的验收。

<a id="fr-33"></a>
**FR-33 来源权限。** 可查看/修改既有用途与接收范围，撤权、来源变化、删除抑制和派生缓存按原规则生效。设置简洁不省略实际处理去向。

<a id="fr-34"></a>
**FR-34 离线状态真实。** 缓存注明更新时间；离线撤权/删除先限制本机使用并说明 Air 尚未确认，联网核对后才显示远端生效。不能撤回已发送给模型的请求。

<a id="fr-35"></a>
**FR-35 导出恢复。** 导出所选 Markdown、支持的附件、聊天只读记录、记忆只读快照与结构化导出，清单注明范围。恢复先核对文件和冲突，不静默覆盖、不恢复旧授权、不自动触发模型或重建已删除记忆。具体支持格式在实施前定案；本版不承诺完整数据库/会话运行态一键还原。

<a id="fr-36"></a>
**FR-36 设置作为底部主入口。** 设置与日记、导师、记忆并列，位于主导航第四项；目录底部不另设设置栏。设置根页通过底部切换，子页用返回，不再出现通往设置自身的“更多”。离开日记前可靠保存输入；失败或冲突未处理时留在原文。设置承载目录/日期偏好、本人连接、模板/任务、资料与 AI 使用、导出恢复及语音条件项。正文可以保留当前文档操作，但不再用通用“更多”循环进入设置。

### 原模板、周记/月记与每日行动

<a id="fr-37"></a>
**FR-37 完整原模板。** 保留本人原日、周、月模板的标题、字段、任务、表格、属性、链接与占位符，不替换成自造模板。三份本机模板已定位；日期规则、原数据填充仍需核验。未知表达式保留并说明，不执行任意脚本。

<a id="fr-38"></a>
**FR-38 新日期。** 已有文件直接打开；缺失日期按原模板准备，首次编辑或显式保留空白日记后落盘。浏览不自动批量建历史文件；模板不可用保留输入并等待恢复。跨午夜不移动当前文字，日期遵循已选日记时区。

<a id="fr-39"></a>
**FR-39 整天记录保留。** 保留原晨间、MIT、任务、健康/运动、晚间、自省、学习和 Notes 等栏目。未填、未接通数据、真实零值分开处理；原字段和自动填充任务逐项核对，不能因仓库缺实现而删掉用户功能。

<a id="fr-40"></a>
**FR-40 周记。** 打开原周记，或手动选择周期显示准确日期、来源和缺口后按原模板生成，有依据才填写。默认上一完整周，原规则不同则沿用经核验的原规则，当前周注明未结束。

<a id="fr-41"></a>
**FR-41 月记。** 按原月模板和自然月范围整理周记及有日期依据的日记；跨月周按实际日期取材，不重复计数。周记不足可说明降级到日记，缺失不填零、不虚构经历，不自动改北极星。

<a id="fr-42"></a>
**FR-42 草稿与文件。** 手动生成有进度、原模板草稿、正文校正、来源缺口、确认和回执，写入原 weekly/monthly 位置。已有文件先打开，重新生成保留版本和本人修改；失败与未知结果分别恢复，AI 分析不重复提取为本人事实。

<a id="fr-43"></a>
**FR-43 本人北极星。** 沿用原定义、口径、阶段重点和文件位置，可查看和修改；无依据不编造当前数值或目标。修改保留版本，历史计划能查看当时引用定义。

<a id="fr-44"></a>
**FR-44 每天一个 MIT。** 依据本人指标、阶段及获准反馈提出一个建议，说明理由、行动和完成标准；可修改、手填并确认。当前计划唯一，实际反馈分完成/部分/未做，不自动顺延或计完成。正文改过 MIT 后标记与旧确认待核对，不能沿用旧字段登记完成；无关段落修改不触发冲突，旧反馈改动保留差异而不篡改当前计划。

<a id="fr-45"></a>
**FR-45 沿用原任务并可控制。** 日记创建、周记/月记和原字段填充继续按现有 Air 任务执行。设置中可查看真实时间/时区、状态、上次结果和下次计划，手动运行、启停或修改时间；修改等待 Air 确认才显示生效。MIT 可手动请求，也可由本人设置每日生成，未配置时不猜时间或自动开启。先核对原规则、位置、幂等和确认方式再接控制，不重复安装或默改旧任务。新增 AI 写入默认预览确认，既有已授权行为按原规则保留；持续任务先明确资料用途和接收范围，执行时重验。漏跑、失败、未知结果先核对，不无限补跑。

## 4. 质量与验收

- **文件完整：** 已保存内容重开后字节一致，冲突双方、旧草稿和恢复版本不静默丢失，重复请求不重复写。未编辑属性、链接、模板结构和 AI 性质保留。
- **交互可用：** 打开今天、正文编辑、右滑前一天／左滑后一天、竖向滚动、原目录、设置返回、直接私聊及圆桌完整可用。在指定 iPhone 检查输入法、光标、较大字体、VoiceOver、键盘遮挡和表格操作。
- **状态与效果可信：** 分别验证本机保存、iCloud 传播、Air 读取、AI 生成与记忆生效。“手机修改日记 → 按既有授权处理 → 有依据的新记忆 → 导师使用”须真实走通；受控样例中不将计划/AI 建议误计为已发生事实。
- **响应目标：** 指定手机和文档规模下，已有本机日记目标 2 秒内显示，停止输入后目标 1 秒内持久化。目标尚需测量，后台离开与大文档另测，不能用普通重开代替故障验证。
- **旧服务兼容：** 不放宽 private、四用途、接收方、撤权、来源版本和预算；既有飞书、Hermes、Mem0 及任务通过相应回归后才受控更新 Air。
- **个人试用：** 评价记录、查找、续聊和纠正记忆是否顺畅，不以调用次数、记忆条数、讨论长度作为成功指标。分别记录自动测试、Mac 手动、真机、模型及 Air 证据。

## 5. 实现起点与未决技术条件

现有原生编辑、本地恢复、只读目录和手动工作流作为增量起点；原位 iCloud 写入、Air 手机入口、原模板真实生成、原生导师/记忆界面仍需完成。原型通过不表示这些功能已实现。

开发者在对应阶段验证：目录授权与冲突、本人手机访问 Air 的路径和身份、App/飞书历史衔接、North Star 原配置与任务规则、导出恢复格式、机型/系统/签名及免费听写效果。功能范围已确认；若技术证据要求改变体验，再说明具体影响。依赖、负责人角色和通过条件见[开发计划](product/ios-personal-mvp-development-plan.md)。
