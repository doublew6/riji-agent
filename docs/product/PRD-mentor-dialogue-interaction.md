# 导师私聊与群聊

当前为 **v0.3.3：2026-10-17 用户已确认“在导师首页直接聊天，不跳页面”，已实现并通过本轮本机回归，待用户体验确认**。先看[图解讨论版](../../_bmad-output/planning-artifacts/prds/prd-riji-agent-2026-10-14/visual-prd.html)，完整规则与确认记录见[文字 PRD](../../_bmad-output/planning-artifacts/prds/prd-riji-agent-2026-10-14/prd.md)。这次确认覆盖 v0.3.2 中“首页点群 → 群聊天页”的解释；旧稿已存入 [history/v0.3.2](../../_bmad-output/planning-artifacts/prds/prd-riji-agent-2026-10-14/history/v0.3.2/prd.md)。

**找一位导师，点上方人物进入私聊；和几位一起聊，就在导师首页下方聊。** 上方保留北极星和四位导师，下方直接放当前群的消息与输入框。通过群切换控件原位换群，同时只显示一个活跃群；没有群级返回按钮，也不用先打开群聊天页。建群完成后在同一首页显示新群，群详情、改名、归档与恢复保留为辅助操作。键盘和大字号优先让消息与输入获得空间。

每个导师仍只有一个固定私聊入口；群可以围绕一个话题，也可以长期使用。各私聊与群分别保留历史、草稿、阅读位置、真实回复状态及保存来源。旧圆桌在同一首页显示原消息，保留原身份、主持人和实际接收范围。切换页面布局不扩大资料权限、不自动带入其他聊天，也不改变 AI 结果预览确认。视觉继续沿用 [F · 北极星指引](../design/mentor-dialogue.md)。

历史验证：[2026-10-15 群聊实现](../testing/ios-mentor-groups-2026-10-15.md)、[2026-10-16 首页直达群聊](../testing/ios-mentor-flat-list-2026-10-16.md)。这些记录只证明当时版本，不代表本轮首页内联聊天已经通过验收。本次仅进行本地开发与合成数据模拟器验证，Air 部署与真机安装另行执行。

本轮实际截图、失败修正记录和验收范围见[首页直接群聊测试记录](../testing/ios-mentor-inline-chat-2026-10-17.md)。App 版本为 **0.1.0（构建 2）**。
