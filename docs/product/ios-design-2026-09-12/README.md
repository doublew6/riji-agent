先打开 [低保真全流程图](wireframe-riji-ios.html)，再对照 [新版 PRD](../../PRD.md)。全部 **102 个界面与状态示意、13 组流程、45 项功能要求** 默认展开；点击按钮可跳到对应页面。每屏下方可以写批注，批注保存在当前浏览器，可导出 Markdown。移动文件、换浏览器或清除浏览器数据可能影响批注，应及时导出。

本轮按用户反馈补齐原日记功能：**按模板建日 → 北极星与每日 MIT → 白天记录和晚间实际反馈 → 周报 / 月报 → 下一步行动**。这些均为首版必需。日常自动化读取并迁移 Air 的实际原任务，不使用 pack 示例时间冒充运行配置。

当前常用体验：**打开今日正文 → 同页打字或录音 → 保存后仍在当天**。首屏没有配对、建日向导或功能按钮阵列。周报/月报和北极星在日记目录；账号只按需登录，产品后台统一配置。线框多图展示同页状态、底部弹层和条件分支，不代表用户要依次经过这些页面。

优先走查：[今日正文](wireframe-riji-ios.html#B01)、[页内输入](wireframe-riji-ios.html#C01)、[页内录音](wireframe-riji-ios.html#C03)、[保存后仍在原页](wireframe-riji-ios.html#D03)。旧页面 ID 与浏览器批注键保持，已有批注不会因本轮扩展主动清除。

重点反馈：今日正文与便捷记录、普通账号和维护者配置的分层、手动修改已有日记的提案、个人材料分享给导师的步骤。A1–A8 的默认值与实现前待确认条件都在 PRD 和线框末尾。内容均为虚构示例。
